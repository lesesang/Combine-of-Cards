# Combine of Cards — 컴바인 오브 카드즈

동호회 자작 TCG 《컴바인 오브 카드즈》의 웹 대전 **베타** 구현입니다. 확정된 **v1.3 룰북, 유효한 24개 덱과 254개 카드 항목**을 사용합니다. 제거한 8개 덱의 카드는 포함하지 않습니다. 다른 덱의 카드 혼합도 금지되어 있습니다.

## 시작하기

Node.js **20 이상**만 필요합니다. 외부 npm 패키지를 설치하지 않아도 됩니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 여세요. 두 사람이 이용하려면 이 Node 서버를 HTTPS 프록시 뒤에 배포하고, 친구에게 HTTPS 주소와 대전방 코드를 공유하세요. `PORT=8080 npm start`로 포트를 변경할 수 있습니다.

```bash
npm test
npm run check:data
```

## 구현된 기능

- 반응형 홈, 덱 라이브러리, 카드 효과 도감과 검색, 기본 룰북
- 2인 대전방 생성·참가, 방별 비밀 토큰 인증, 영속적 대전 상태 (단일 Node 인스턴스)
- 안전한 서버 측 덱 섞기와 드로우, 빈 덱 리로드(100부터 50씩 상승), 손패 비공개
- 메인/어택/엔드 및 매 턴 드로우, 몬스터·일체화 소환, 1d공격력 피해, 필드 3칸, 체력 0 패배 및 동시 무승부
- 공격 후 상대 대응 확인, 상대 효과로 대상이 사라지면 재선택, 서버 판정 로그
- 복잡한 카드 효과는 **상대 승인 기반 수동 판정**: 체력·능력치 조정, 카드 이동, 추가 드로우, 엑스트라 소환 및 기록
- 요청 버전 확인, 본인 플레이어 권한 검사, 정적 파일 경로 방어, CSP, 소규모 레이트 리밋 및 기본 API 테스트

## 반드시 알아야 할 제한

**254개 카드의 개별 특수 효과가 모두 자동으로 처리되지는 않습니다.** 본 사이트는 베타입니다. 각 카드의 조건·소재·어그로·방어·강화·일체화 진화·특수 소환 효과를 정확히 적용할 책임은 참가 플레이어에게 있습니다. 서로 승인한 수동 판정만 서버가 수행하며, 승인된 판정도 원문의 합법성을 서버가 검증한 것은 아닙니다.

덱 선택과 카드 목록은 고정되어 있으며 플레이어가 덱을 혼합해 편집할 수 없습니다. 일체화 일반 소환은 지원하지만 진화, 지속 효과 및 반응형 효과의 전자동 처리에는 카드 효과 구조화 및 추가 테스트가 필요합니다. 완전 자동 대전 또는 공개 운영을 보장하지 않습니다.

## 구조

- `server.mjs` — 의존성 없는 HTTP 서버, 비밀 정보 분리, 게임 상태 기계와 저장
- `public/index.html`, `public/style.css`, `public/app.js` — 한국어 반응형 인터페이스
- `public/data/catalog.json.gz.b64` — v1.3 카드 목록 (gzip+base64; 서버가 API JSON으로 제공)
- `tests/engine.test.mjs` — 서버 통합 테스트
- `scripts/build-data.mjs` — 별도 제공된 정본 JSON으로 카드 목록을 다시 생성하는 선택적 도구
- `scripts/verify-data.mjs` — 덱 장수, 삭제 덱, 카드 수 검증

## 배포와 데이터

서버 상태는 기본적으로 `.data/rooms.json`에 원자적 파일 교체로 보관합니다. 배포 시 `DATA_DIR`을 **쓰기 가능한 영속 볼륨**으로 지정하세요. 재배포 시 저장 파일을 보존해야 합니다. 단일 Node 프로세스 전용으로 작성되었고, 여러 서버 인스턴스를 실행하려면 DB 및 동시성 제어 계층이 필요합니다. GitHub Pages나 Cloudflare Pages의 단순 정적 호스팅만으로는 대전 API가 작동하지 않습니다.

HTTPS 역방향 프록시, 적절한 백업, 악성 요청 제한, 관측·에러 복구, 운영용 계정 체계는 정식 공개 전에 추가해야 합니다. 대전방 접근 토큰은 브라우저 `localStorage`에 보관되므로 공유 장치에서는 주의하세요.

## 라이선스

원작 카드 텍스트와 아트워크의 저작권·배포 범위는 해당 제작자의 권리에 따릅니다. 이미지 자산은 포함하지 않았습니다.

## AI 대전 및 효과 자동 판정 확장 (베타)

`POST /api/ai`로 1인 대전을 시작할 수 있습니다. 인간의 `deckId`, 상대 `aiDeckId`(또는 `random`), `difficulty`(`easy` / `medium` / `hard`)를 지정합니다. 난이도별 행동 선택은 **서버 측 규칙 기반 휴리스틱**입니다. 사람의 카드 정보는 AI 대전 API 응답에 공개되지 않습니다.

자동으로 처리되는 카드 효과는 `src/automated-effects.mjs`의 **ID별 지정 핸들러**에 한합니다. **미지원 주문은 AI 대전에서 사용할 수 없고 소모되지 않습니다.** 지원 카드의 일부 효과만 자동화된 사례도 있어 254개 전체 카드의 완전 자동 판정이라고 볼 수 없습니다. 세부 목록과 권장 수정은 [AI 자동화·판정 보고서](docs/AUTOMATION_AND_RULINGS.md)를 참고하세요.

npm test
npm run check:data

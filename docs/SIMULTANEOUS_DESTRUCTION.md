# 동시 파괴 판정 검증 (v1.3)

《컴바인 오브 카드즈》에서 하나의 효과로 여러 몬스터를 동시에 파괴할 때, **각 파괴 대상의 효과 해결 전 현재 체력**을 먼저 기록한 후 파괴를 진행한다.

- `언데드 / 시신 섭취` 등 첫 파괴에 반응하는 효과는 같은 사건에서 파괴된 몬스터 중 가장 높은 파괴 직전 체력을 참조한다.
- 파괴 대상이 0장이면 첫 파괴 효과를 소비하지 않는다.
- `간드레이드래곤`은 자기 자신을 제외한 몬스터만 동시 파괴 대상으로 잡는다.
- `환희의 마법 – DARKNESS`(코인 앞면), `원소 마법 – 어스 퀘이크`, `폭풍! 수은!`의 몬스터 2장 파괴, `잠든 황제 셔우롱`의 전체 파괴를 한 번의 파괴 대상 집합으로 처리한다.

## 엔진 범위

`H.destroyBatch`는 **파괴 전 체력 참조용 스냅샷과 첫 파괴 회복** 판정의 일관성을 보장한다. **모든 동시 발동 효과의 우선순위/체인 해결까지 전자동으로 검증한 것은 아니다.** 해당 범위는 효과 스택과 반응형 트리거 엔진이 필요하며 후속 검사 대상이다.

회귀 테스트: `tests/simultaneous-destruction.test.mjs`.

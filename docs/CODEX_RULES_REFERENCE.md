## 2026-10-14 사용자 명확화 — 서로 다른 실제 카드의 효과는 별개

사용자: **“동일 효과가 전부 1턴 1회는 아니야. 같은 효과라도 카드가 다르면 별개로 발동 가능해”**.

사용 기록은 **실제 카드 UID + 효과 번호**로 구분한다. 동일 효과 문구·카드 이름·같은 카탈로그 ID를 가진 서로 다른 실제 카드까지 한 번으로 묶지 않는다. 각 카드의 명시적 턴당/게임당/재소환 제한은 유지하며, 이번 설명을 모든 효과의 전역 턴당1회 규칙으로 해석하지 않는다. 복사 엔진 완성을 뜻하지 않으며 이미 확인한 룰은 재질문하지 않는다.


## 2026-10-14 사용자 정정 — 라이징 윈드 걸은 몬스터 효과만

사용자: **“라이징 윈드 걸의 효과는 몬스터의 효과만 무시야. 그걸 반영해서 다시 정리하고 텍스트도 바꿔줘”**.

COC-12-002의 플레이 카탈로그 문구를 “1회 상대 효과를 무효로 합니다.”에서 **“1회 상대 몬스터의 효과를 무효로 합니다.”**로 정정한다. 상대 주문·일체화 스톰블레이거의 효과·소환 자체는 대상이 아니다. **재소환 시 재사용 가능**은 유지한다. PR #68의 더 넓은 대응 범위는 이 정정으로 대체하며 다시 묻지 않는다. 현재 구현은 등록된 몬스터 카운터3종 및 등록된 필드 몬스터 발동15종의 효과 대응이며, 모든 몬스터 발동·유발을 완성한 것은 아니다. [구현 명세](FIELD_COUNTER_CHAINS.md).


## 2026-10-14 사용자 확정 — 필드 무효화 카드 3종의 재사용

블래스트 보이(COC-12-001), 라이징 윈드 걸(COC-12-002), 디텍티브 매치(COC-24-005)의 “1회” 초기화 시점 질문에 사용자가 **“다시 소환되면 재사용 가능”**이라고 답했다. 같은 필드 체류 중 1회 사용하며 재소환하면 다시 사용할 수 있다. 단순 조종권 이동·재접속은 재소환이 아니다. 이 세 카드를 게임당1회로 고정하지 않는다.

스톰블레이거(COC-14-001)는 기존 확정대로 **동일 실제 카드의 주문/소환 무효화 합계 게임당1회**를 유지한다. 이 차이를 다시 묻지 않는다. [구현/남은 범위](FIELD_COUNTER_CHAINS.md).

## 2026-10-14 사용자 확정 — 소환 무효된 엑스트라 카드

스톰블레이거가 퓨전·라피드·얼라이즈 소환을 무효화했을 때 해당 몬스터의 이동 장소 질문에 사용자가 **“엑스트라 덱에 유지”**라고 답했다. 지불 소재·주문 비용은 R22대로 반환하지 않는다. 해당 카드를 필드/묘지로 옮기거나 소환/필드 파괴 유발을 발생시키지 않는다. **이 결정은 다시 묻지 않는다.** 일반 패 소환 무효 시 카드 이동 장소까지 이번 답변으로 확장하지 않는다.

사용자는 이어서 스톰블레이거(COC-14-001) 원문의 “주문의 발동 또는 몬스터의 소환을 한 게임당 1회”가 **동일 카드의 주문/소환 무효화 합계 1회**라는 설명에도 “아 그럼 맞아. 계속해줘”로 동의했다. 주문 1회+소환 1회의 별도 횟수가 아니며 다른 카드까지 적용하는 전역 제한이 아니다.

기존 진화 기본값 교체+강화 유지/패·덱·묘지 원본 복원, 17개 공식 확정, 최신 마검·장착 해제 금지·간드레이드래곤 자기 제외는 변경하지 않는다. [구현/잔여 범위](EXTRA_SUMMON_COUNTERS.md).

## 2026-10-14 사용자 확정 — 진화 수치와 원본 복원

사용자가 미확정 진화 질문 2개에 직접 답했다. 아래 두 항목은 **확정 재정**이며 다시 묻지 않는다.

1. “새 기본값으로 교체하고 강화 유지: 200”. 기본 ATK 100 + 강화 50인 베리아가 기본 ATK 150 스트로베리아로 진화하면 **200**이다. 기존 단순 합산 300은 오류다. UID·원소유자·현재 공격 횟수·지속 효과를 유지한다.
2. 패·덱·묘지로 이동하면 “원래 카드로 복원”. 진화 최초 원본 카드 ID로 복원하고 기존 영역 이동 수치 초기화 규칙을 적용한다. **제외 영역은 질문에 포함되지 않았으므로 이번 확인으로 새 복원 규칙을 확장하지 않는다.**

기존 마검 최신 재정·자의적 장착 해제 금지·간드레이드래곤 자기 제외·17개 공식 확정 재정은 변경하지 않는다. 진화 카드의 별도 효과를 모두 구현했다는 뜻은 아니다. 구현과 남은 범위: [EVOLUTION_AND_DECK_SEARCH.md](EVOLUTION_AND_DECK_SEARCH.md).

| 복사/무효 | 소환 조건 무시로 사용 금지 무시 불가. 일반 필드 효과가 해결 전 필드를 떠나면 무효, 명시된 파괴 시/묘지/자신을 비용으로 보냄/독립 지속/깐깐한 감독관 예외는 보존 |
| 다이스 범위 | 효과 변경으로 하한 > 상한인 동안 유효 하한만 조정; 상한이 다시 커지면 원래 하한 복원 |

**자체 카드 조합/새 덱 제작 기능을 요구한 적 없음.** 현 프로젝트는 사용자가 제출한 덱 그대로 선택해 대전하는 서비스다.

## 4. 승인된 엔진 정책 6개

1. **필드 소스 이탈 무효와 예외**: 일반 필드 효과는 해결 전 발동 소스가 떠나면 무효. 파괴 시/묘지에서/자기 비용으로 이동/이미 별도 등록된 지속 효과/깐깐한 감독관은 정해진 예외.
2. **독립 지속 효과**: 주문 본체가 묘지에 가도 기간·카운터·종료 사유를 가진 효과 인스턴스는 별도 유지(라인의 황금, 마검).
3. **체인/동시 선언 우선순위**: 명시된 특별 우선도, 현재 턴 플레이어가 동일 우선도 발동 순서를 먼저 선택한 뒤 상대 순서 선택, 이후 **후발 먼저 해결**.
4. **복사 스냅샷/독립성**: 원본·복사 실행자·복사 시점 카드/사건/사용기록·이후 독립 누적. 조건과 비용과 처리 단계 분리.
5. **현재/실제/취급 공격력**: 서로 다른 판정 값의 타입 보존, 임시/영구 버프와 기간 구분, 복합 배율을 함부로 실수치에 영구 적용하지 않음.
6. **합법 반복 보존/무한 루프 탐지**: 실제 상태 변화 있는 반복은 계속 허용. 완전히 동일한 상태/스택만 탐지하여 안전하게 중단·설명. 베타의 고정 안전 한도를 게임 룰로 선언하지 않음.

# 잔여 구현·검증 및 실제 미확정 판정 등록부 (13개 트랙)

## 2026-10-16 소환·검색 묶음 개발자 판단 — 미검증

[묶음 명세](SUMMON_TRIGGER_BATCH_DRAFT.md)에 렌의 누락 비용, 스플래쉬 소환 조건/효과 분리, 스파클링 양쪽 대상, 카스테 선택 후 코인, 케미 자기 사용 주문 회수, 율리우스 상대 턴 소환 기간, 티라노 HP 미정 처리와 남은 충돌을 모았다. 기존17확정 및 사용자 확정 규칙은 유지한다. 사용자 신규 확정으로 기록하지 않으며 테스트/CI는 일괄 검증 때 수행한다.

## 2026-10-15 진화·소환 연계 개발자 해석 — 미검증

진화 사용 이력은 서로 다른 물리 UID를 세고, 네 종류의 여러 장 소환은 각 카드의 대응/유발 해결 후 다음을 선언하도록 작성했다. 후보 부족/빈 칸만큼 처리·부활 조건 면제·일반 소환 무효 시 패 유지·야시키 지속 층·흉담 지연 비용·26번 매치 파괴 반사 귀속은 사용자 위임에 따른 개발자 해석이다. 기존17확정은 변경하지 않았다. [상세 정책·구 저장 한계·미완료](EVOLVED_AND_SUMMON_AUTOMATION_DRAFT.md). 테스트/CI는 보류하며 이슈 완료로 인증하지 않는다.

## 2026-10-15 구현 우선 후속 — 미검증

Draft PR #75에서 플레임/볼케이노 독립 대응과 귀속 파괴, 프람덴베르카/슈 이력 조건을 작성했다. **미검증이며 이슈 완료 처리하지 않는다.** 슈의 연속3개 완전한 게임 턴 및 원소유자별 배회자 죽음 귀속, 새 파괴 유발의 현재 체인 완료 뒤 선언은 사용자 위임에 따른 개발자 해석이다. 기존 사용자 확정을 바꾸지 않았다. [근거·구 저장 한계·일괄 검증 계획](ELEMENTAL_TRIGGER_AUTOMATION_DRAFT.md).

**2026-10-13 공식 확정된 17개 규칙(R05~R30 중 해당 ID)은 [RULINGS_CONFIRMED_2026-10-13.md](RULINGS_CONFIRMED_2026-10-13.md)로 이관했다. 이 문서는 남은 13개의 기술 구현·검증 트랙이다. 13개 전부가 사용자에게 결정을 받아야 하는 '미확정 재정'인 것은 아니다.** 사용자에게 이미 확정받은 결정은 docs/DECISIONS_AND_CORRECTIONS.md에 있고, 이 문서는 *현재 실제 코드가 선택한 임시 동작*과 *아직 확인할 해석*을 구분하여 다음 채팅에서 오류로 삼거나 새 결정을 요청할 수 있도록 한다.

- **확정**: 사용자가 분명히 결정했고 수정 금지(별도 공식 변경 시 제외).
- **임시 구현**: 현재 코드가 선택했으나 원문/대화 기준으로 사용자 확정이 부족할 수 있음.
- **미구현**: 실제 지원하지 않으며, 명세/일관성/코드 필요.
- **검증 필요**: 일부 지원하지만 악의적·극단 조합과 전체 효과를 증명하지 못함.

새 채팅에서는 이미 **확정**된 항목을 다시 질문하지 말고, 이 파일에 있는 우선순위 높은 **구현·검증 과제**만 관련 기능 구현 시 함께 검토한다.

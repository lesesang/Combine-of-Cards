# 잔여 구현·검증 및 실제 미확정 판정 등록부 (13개 트랙)

**2026-10-13 공식 확정된 17개 규칙(R05~R30 중 해당 ID)은 [RULINGS_CONFIRMED_2026-10-13.md](RULINGS_CONFIRMED_2026-10-13.md)로 이관했다. 이 문서는 남은 13개의 기술 구현·검증 트랙이다. 13개 전부가 사용자에게 결정을 받아야 하는 '미확정 재정'인 것은 아니다.** 사용자에게 이미 확정받은 결정은 docs/DECISIONS_AND_CORRECTIONS.md에 있고, 이 문서는 *현재 실제 코드가 선택한 임시 동작*과 *아직 확인할 해석*을 구분하여 다음 채팅에서 오류로 삼거나 새 결정을 요청할 수 있도록 한다.

- **확정**: 사용자가 분명히 결정했고 수정 금지(별도 공식 변경 시 제외).
- **임시 구현**: 현재 코드가 선택했으나 원문/대화 기준으로 사용자 확정이 부족할 수 있음.
- **미구현**: 실제 지원하지 않으며, 명세/일관성/코드 필요.
- **검증 필요**: 일부 지원하지만 악의적·극단 조합과 전체 효과를 증명하지 못함.

새 채팅에서는 이미 **확정**된 항목을 다시 질문하지 말고, 이 파일에 있는 우선순위 높은 **구현·검증 과제**만 관련 기능 구현 시 함께 검토한다.

> **Codex 최신 참조:** [통합 인수인계](CODEX_HANDOFF.md) · [17개 확정 규칙과 카드별 교정](CODEX_RULES_REFERENCE.md) · [작업 PR 계획](CODEX_IMPLEMENTATION_PLAN.md). 최신 코드 기준: 157 partial / 96 manual / 1 basic, 효과별 증거 6건, 주문 핸들러 71, 실제 주문 응답 스택 15종. 역사 PR 당시 지원 수치를 현재 수치로 오인하지 않는다.

## 2. 룰은 확정되어 다시 묻지 않아도 되는 항목

- **간드레이드래곤 자기 자신은 전체 파괴 대상 제외**: 사용자 최신 확정, PR #10 및 docs/GANDRAE_RULING.md. 미확정 항목으로 취급하지 않는다.
- **반지 선해결 후 라인의 황금 삭제**와 **플레이어 체력/공격력 강화**, **R05~R08 토큰 사건·양쪽 황금·플레이어 공격력 귀속**은 모두 공식 확정. 전역 이벤트/슬롯/소유권 통합은 여전히 미완료.
- **복사 조건 무시 범위**: 조건에 포함된 비용은 무시, 효과 처리 중 발생하는 비용과 사용 금지는 무시 불가. 불분명한 것은 **구체적인 카드 텍스트의 비용 분류**뿐이다.
- **동시 패배 무승부**, **리로드 피해 +50**, **상대 대응으로 공격 대상 소실 시 재선택**, **소환 직후 공격 가능**, **파괴 직전 최고 현재 HP 참조**, **얼라이즈 소재 동반 이동**, **카툰 랜드 이름/카툰 포함 판정**은 확정.
- 사용자가 선택한 **6개 엔진 개선안**은 공식 요구사항. 변경을 제안할 때 사용자 승인 없이는 임의로 철회하지 않는다.
- 배포가 아직 없는 것과 미구현 효과는 **규칙이 미확정이라는 뜻은 아니다**. 기술 미완료와 룰 해석 미확정을 혼동하지 않는다.

## 3. 발견 즉시 처리하는 방법

1. 원본 v1.3 카드 텍스트 및 사용자의 확정 결정을 정확히 인용·요약하고, 발생한 **구체적인 판정 시나리오**를 작성.
2. 이미 공식 확정됐으면 문서/코드 오류로 분류하고 즉시 회귀 테스트를 추가해 수정.
3. 정본만으로 결론이 불가능하면 **미확정**으로 유지. 구현 편의대로 임의 규칙을 '정식'으로 표시하지 않음.
4. 실제 임시 코드 동작, 예상 영향 카드/게임 상태, 권장 선택지 A/B와 테스트 시나리오를 같이 제시.
5. 공식 결정 후 이 파일의 항목을 확정 재정 문서로 이관하고 DECISIONS_AND_CORRECTIONS.md + 공식 룰북/JSON + 해당 카드 테스트를 함께 갱신. 원본 JSON 미편입은 별도 작업으로 표기.

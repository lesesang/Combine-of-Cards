## 전체 자동화까지 남은 큰 작업

1. **미구현 몬스터·일체화·엑스트라 조항**: 소환 성공만 처리하는 카드도 고유 효과가 남는다. 앞서 직접 미연결10장의 실행 경로는 작성했다. 이제 전254장 조건과 각 효과 번호를 소스에 대조하여 아직 발견하지 못한 누락까지 분리한다. 원죄21-001은 [새 복사/계승 묶음](COPY_INHERITANCE_SHARING_DRAFT.md)에 선택 등록198조항과 독립 이후 이력/사건·지속 능력 경로를 작성했다. 실물 이동·진화·이름 취급·황금 연결 등 명시 미지원 번호는 남는다. 다른 몬스터 능력 계승, 와이번11-004의 패/덱/필드 이동은 별도 발동/대응 경로를 작성했다. 각 덱의 남은 발동/피해/사망 유발을 효과 번호별로 마무리해야 한다.
2. **지속 효과와 능력치 합성**: [공통 배율](STAT_GAINS_AND_DRAGON_PHASE_DRAFT.md)에 용왕×1.5/꽝철이 반감, 일회성 강화·회복, 임시 만료/영구 복원, 지속 오라 재계산을 연결했다. 용왕/오로치의 어택 시작 피해도 공통 유발에 추가했다. 인형의 주요 지속 오라·동시 교환/복귀·기본 복사 공유는 이번 묶음에 작성했다. 남은 범위는 특수 변환 조항과, 이전 저장에 섞여 있는 파프니르 성장량의 명시적 이관과 전역 사건의 정합성, 아직 연결되지 않은 효과/복사 조항과 전수 상호작용이다. 모든 수치 경로·소스 출입·무효 조합을 검증한 것은 아니다.
3. **자동 소환·토큰·복잡한 재사용**: 황금의ATTACK 유발과 반지의 파괴 보상은 공통 대응으로 옮겼다. 토큰 생성6종/파프니르 자동 소환/황금 첫 사용은 순차 대응으로 작성했다. 카툰 사망 연계/랜드 소환도 중단·재개를 작성했다. 남은 전역 체인 통합, 묘지 소재 소환, 생성·파괴·이동의 정확한 사건과 재사용의 실물 원본/진화/공격 연속 처리를 연결해야 한다.
4. **엔진 공통 정합성**: 동시 피해/파괴/회복 순서, 중첩된 대응/선택/부활/공격의 재개, 전 카드 실물별 횟수와 예외, 상대 턴 행동, 소스와 대상 재진입, 무한 루프 안전 중단을 전수 점검해야 한다. 공통 경로가 있어도 모든 카드에 연결되었다는 보장은 없다.
5. **전 카드 증거·PvP·AI 검증**: 카탈로그254장의 모든 효과/조건을 인벤토리에 연결하고, 보류된 PR 전체 회귀·불법 요청·비공개 정보·저장/재접속·AI3난이도·24×24매치업을 수행해야 한다. 기본 행동 가능과 상 난이도 전술 품질은 별개다. Node tests/Verify TCG beta가 둘 다 성공한 뒤 병합한다.
6. **배포와 D1**: 개인 D1 저장 어댑터·스키마·방 버전 원자성/동시 요청·세션·복구·마이그레이션/롤백은 별도 작업이다. 지금까지의 새 대기열은 JSON이지만 실제 D1 연결/운영 이관은 미실행이다. 정본 v1.3 DOCX/원본 비교 자료는 저장소에 없는 상태로 남아 있으며 새로 창작하지 않는다.

## 예상 작업량과 진행 순서

이전의 주 단위 추정은 검증 전의 거친 가정이었다. 이번 직접 미연결 목록과 남은 복사/공유를 포함해254장 전수 대조가 끝나기 전에는 확정 완료일을 제시하지 않는다. 실제 카드별 완료율도 등록 핸들러 수로 환산하지 않는다. D1/운영 이관은 카드 효과 구현과 별도 작업이다.

속도를 높이기 위한 다음 단위는 카드1장씩이 아니라 다음 효과군이다:

1. 복사/계승·복합/지속 공유 묶음의 남은 물리/정체성 조항을 구체적인 미지원 번호표대로 연결하고 254장 전수 조건/조항을 대조한다. 직접 효과 구현과 원죄 복사 지원은 별도 상태로 관리한다.
2. 254장 조건/효과 번호·전역 사건/수치 합성·중첩 대응/선택 재개를 대조하고 새로 확인된 누락을 묶어 작성한다. 토큰/용/카툰/블랙 메탈/이번10장의 작성 경로를 다시 미작성으로 세지 않는다.
3. 구 저장의 미분리 성장·부족한 이력은 추정하지 않고 버전 고정/명시적 이관 정책으로 처리한다.
4. 사용자 요청의 후속 일괄 검증에서 누적 회귀·PvP/AI·저장/비공개/동시 요청을 확인하고 Node tests + Verify TCG beta 통과 후 병합한다. D1 운영 연결과 안전 배포는 별도 단계다.

주문109종의 진입 경로를 작성했어도 전체 자동화는 완료가 아니다. 원죄의 나머지 복사·인형의 복합/지속 공유·전역 상호작용과 누적된 미검증 코드를 완료로 인증하지 않는다.

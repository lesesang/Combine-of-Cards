## 공통 수정과 개발자 판단

저주 파괴의 원인 카드 ID를 자동 주문 피해/파괴/배치 및 소환 비용에 전달한다. 마검의 지불 불가 파괴에도 원래 주문/시전자 원인을 연결하되 확정된 지불 시점·수치·배수·파괴/패배 처리는 바꾸지 않았다. HP부족의 상태 파괴와 효과 파괴 면역도 구분한다.

몽마 봉쇄는 효과 무효와 다르다. 이미 선언한 효과를 소급 취소하지 않고 필드 발동·카운터·새 자동 유발·공격 선언을 차단한다. 지속 오라는 유지한다. 유인 대상은 합법적인 경우에만 강제하며, 도발의 합법 대상을 무시하지 않는다. 대상 지정 발동은 선언 때 유인을 소모하고 자동 유발은 강제 대상 정보를 선언 스냅샷에 보관하므로 나중에 무효화되어도 환불하지 않는다.

귀족의 영구 강화는 실물 상태이고 새 기본 복사본은 상속하지 않는다. 길 잃은 원혼/G-툴처럼 소환 시 기본 수치를 다시 만드는 경로에서도 영구 강화 재적용을 추가했다. 전체 능력치 설정/반감/진화/복사 간 결합은 별도 전수 검증이 남는다.

`card-patches.json`에 `SIN-DEMONS-2026-10-16-DRAFT`로4장 전후/이유를 기록했다. 원죄의 기존 확정 효과 문단은 유지하고 선택 정보 범위 등을 **개발자 주석**으로 추가했다. 몽마의 모호한 만료, 귀족의 대상/지속 범위, 호루스의 범위/대화 잔재를 명확화했다. 사용자 위임에 따른 개정이며 새 개별 확정 답변으로 표시하지 않는다. 원본은 ce08e81의 런타임 카탈로그이며 저장소에 없는 정본을 창작한 것이 아니다.

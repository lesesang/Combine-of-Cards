# 간드레이드래곤 재정 보정 (v1.3)

- 카드 ID: `COC-27-004` (슈페리얼 덱)
- 사용 비용: 해당 카드를 제외하고 자신의 패에 남은 카드를 전부 묘지로 보낸다.
- 소환 후 효과: **간드레이드래곤 자신을 제외한 양쪽 필드의 모든 몬스터를 파괴한다.**
- 효과 결과: 간드레이드래곤은 이 효과로 파괴되지 않고 필드에 남는다. 상대 몬스터와 자신의 다른 몬스터는 파괴한다.
- 다른 효과로 파괴될 수 없는 상태·파괴 시 효과 등은 각 카드의 별도 확정 재정을 적용한다.

## 회귀 검증

`tests/activation-integration.test.mjs`에서 소환 비용을 지불한 후 자기 자신이 필드에 남는지, 아군의 다른 몬스터 및 양쪽 상대 몬스터가 묘지로 이동하는지 검사한다.

이 변경은 간드레이드래곤의 효과 대상 지정만 수정한다. 다른 카드의 전체 파괴 효과에 임의로 자기 제외 규칙을 적용하지 않는다.

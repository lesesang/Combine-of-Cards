## P2. AI 대전의 정확성과 난이도

- [ ] AI 행동 가능 목록은 **같은 서버 규칙 검증기**에서 생성한다. 미지원 효과를 건너뛰고 진행하는 임시 처리 제거.
- [ ] 소환·공격·대응·턴종료뿐 아니라 복사·장착·묘지 효과·상대 반응·엑스트라 소재·비공개 선택의 합법적 선택을 모두 지원.
- [ ] **하:** 합법 행동 중 단순 확률적/무작위, 일부 기회 놓침 가능하되 *불법 행동 없음*.
- [ ] **중:** 필드 전력·즉시 피해/HP 회복·위협 제거·공격 기회·단순 콤보 고려.
- [ ] **상:** 다단계 전개/자원 교환/생존·킬/상대 강제 공격/리로드 위험/체인 응답 등 심화 휴리스틱 또는 탐색.
- [ ] 상대 **비공개 손패·덱 순서 등을 AI 전략에 사용하지 않음**. 서버는 판정용으로 보유하되 AI가 입력받는 관찰 상태와 구분한다. 합법 공개 효과는 별도 권한 창.
- [ ] 난수 시드, 행동 예상 이유, 턴당 반복 중단 원인과 판정 로그; 무한 루프에서 불법 종료·패배를 임의로 선언하지 않음.
- [ ] 지정 덱/랜덤 덱, 하/중/상, 선후공 모두 실제 완주 가능한 시뮬레이션.

**수락 기준:** AI가 모든 유효 덱에서 게임을 완주하고 모든 동작을 서버가 합법으로 승인. 난이도별 행동 차이를 정량적으로 측정하고, 숨긴 카드 정보를 알지 못한다는 보안 회귀 테스트 통과.

## P2. UI / 사용성 / 운영자 테스트 대전

- [ ] 단계별 카드 선택/비용/대상/정확한 행동 완료/실패 사유, 체인 대응 창과 패스/자동 발동 순서 선택.
- [ ] 카드의 자동화 진행·카드 효과 설명, 자신의 패와 공개 가능한 카드의 제한적 정보, 영속 효과/카운터/장착/소재/진화 시각화.
- [ ] 리플레이 가능한 대전 기록/검색 및 재정 판정 로그(플레이어에게 공개된 범위).
- [ ] 관리자/개발자 **테스트 대전 모드**: 두 덱·양쪽 HP·패·필드·코스트·난수 고정, 특정 카드 충돌 즉시 재현.

## 공통 대응과 물리 카드 추적

기존 `onCartoonLandDestroyed`는 `H.destroy` 안에서 자동 그룹을 선언하고 즉시 `resolveEffectStack`을 호출했다. 다른 주문/소환/회복의 부모 스택이 남아 있으면 무관한 항목까지 소비할 수 있었다. 새 훅은 랜드 묘지 체류, 파괴 당시 조종자, 같은 쪽 드래곤의 필드 체류, 덱에 있던 가이드 후보만 JSON 사건으로 기록한다. 요청의 현재 실행을 마친 후 드래곤 유지 조건 파괴를 처리하고 가이드를 공통 유발 대응으로 선언한다.

가이드가 주문으로 분류되어 스톰/블래스트/매치 대응을 받으며 윈드 걸은 가이드 주문/랜드 소환에 대응하지 못한다. 드래곤 처치 피해는 몬스터 효과, 드레이나블은 일체화 효과다. 스톰의 게임당 공용1회와 다른 세 카드의 재소환 초기화는 그대로다.

룩스 비용 등에서 생긴 가이드 사건은 부모 소환과 대기 스택을 저장하고 먼저 해결한다. 가이드 해결로 생긴 랜드 소환도 아직 남은 하위 유발보다 먼저 별도 대응을 연다. 소환 작업에 대응 프레임 깊이를 저장하여 더 위의 새 묘지 유발은 먼저 해결하고, 기존 부모는 랜드 소환 성공/무효/불발 이후 재개한다. 토큰 작업과 일반 부활/연속 소환/턴 전환/전체 공격은 이 작업을 기다린다. 승패·항복 때 새 대기열을 비운다.

소환 직전/해결 시 랜드의 UID·원래 묘지 소유자·영역 이동 번호와 빈 필드를 확인한다. 조종권과 원래 소유자를 구분하며, 다른 랜드나 재진입한 원본을 대신 쓰지 않는다. 가이드 비용은 한 번만 낸다. 랜드 복귀 때문에 원래 룩스 소환의 마지막 빈 칸이 없어지면 룩스는 패에 남고 이미 지불한 두 장 비용은 돌려주지 않는다.

## 위임에 따라 명확히 한 경계

- 드래곤의 유지 조건 파괴는 발동 효과가 아니므로 무효/효과 파괴 면역으로 유지 조건을 우회하지 않는다. 실제 랜드 파괴의 확정 선행 순서는 다른 랜드가 남아 있어도 유지한다. 비파괴 이탈에는 가이드를 발동하지 않지만 자기 랜드가 전부 없어지면 드래곤 유지 조건은 적용한다.
- 드래곤 처치 피해는 각 실제 상대 몬스터 처치 사건에 반응한다는 예외를 명시한다. 일반 효과 전체의 횟수 규칙을 바꾸지 않으며, 피해량은 파괴 후 초기화된 인쇄ATK가 아닌 파괴 직전 마검 배율/지속 강화 포함 실제ATK의 절반을 버림한다. 비용·조건 파괴로 보상을 만들지 않는다.
- 가이드는 파괴 사건마다1장, 같은 실물당 한 턴1회다. 후보가 여러 장이면 UID 정렬로 한 장을 선택하여 비공개 덱 순서를 노출하지 않는다. 여러 랜드 파괴에는 다른 실물 가이드가 별개로 사용된다. 주문 사용 금지 중에는 덱에서 사용하지 않는다. 이미 사용한 가이드의 같은 턴 리로드는 사용 횟수를 초기화하지 않는다.
- 카툰의 기본 이름 판정은 유지한다. 이름 조건을 요구하는 룩스 비용과 일반 카툰 취급을 구분한다. 원문 랜드/핸드의 명시적 카툰 취급은 우드 에로우즈의 대상 판정에 적용하되, 무효화된 랜드의 오라는 적용하지 않는다. 랜드 전투 파괴 방지도 효과가 유효할 때 적용한다. 존재 조건은 효과 무효와 무관하다.
- 드레이나블은 자기MAIN에서 두 번 선언하며 소스/대상 조종자·체류를 고정한다. 효과 무효/스핑크스/파괴 면역/대상 이탈에 횟수를 환급하지 않는다. 아군도 흡수할 수 있고 밀짚인형의 한 단계 공유로 추가 파괴가 생겨도 선택 대상 보상만 한 번 받는다. 강화는 현재 일체화 카드에, 회복은 플레이어에 공통 배율을 각각 적용한다. 영구 플레이어 ATK 부여인 반지와 혼동하지 않는다.
- 새 `effectUsageCounts`는 기존 실물/효과별 사용 기록과 함께 저장한다. 기록이 없는 이전 방의 이번 턴 사용 표시가 있으면1회로 간주한다. 모든 효과에2회를 주지 않으며 원소4종의 플레이어별 공용1회 예외도 바꾸지 않는다.
- HP100/랜드HP1·50은 현재값 설정이므로 회복 배율을 곱하지 않는다. 랜드 진입 시 지속 HP 층을 먼저 갱신하고 현재값을 설정한다. 이후 지속 층이 제거되면 일반 차액 규칙을 따른다.

공식17재정, 마검 최신 판정, 자의적 장착 해제 금지, 간드레이 자기 제외, 진화 기본값 교체/영역 이탈 복원 등은 유지한다. R24가 구현 누락이었다는 이유로 사용자에게 다시 묻지 않는다.

## 화면·AI·저장

룩스의 비용 목록은 패/필드를 구별하여 자기 외 이름 조건에 맞는 카드를 제공한다. 서버가 중복·면역·소유자/영역을 최종 검사한다. 필드 발동 메뉴에 남은 횟수를 표시하고 드레이나블 두 번째 발동을 막던 단순1회 AI 검사도 횟수 기준으로 바꿨다. AI가 드레이나블 일체화/상대 파괴 대상을 선택하고, 룩스 비용을 준비하며, 자기 랜드 없는 드래곤 소환·드래곤 직접 공격을 피하도록 연결했다. 전략 품질/완주를 검증한 것은 아니다.

새 큐/카운트/대응 보관은 함수나 Map을 저장하지 않는 JSON이다. 원래 서버의 요청 롤백·방 저장 경로를 이용한다. 개인 Cloudflare D1 연결·버전 원자성·재접속/동시 요청 검증은 남는다. 상대 덱 후보나 내부 대기열은 새 공개 API 필드로 노출하지 않는다.

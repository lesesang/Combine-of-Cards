## 선언과 대응

서버 `ability`가 조건·비용·대상을 먼저 검증하고 비용/사용 기록을 지불한다. 선언된 효과는 `field-ability-resolution`, 대기 상태는 `pendingAbility`에 JSON으로 저장한다. 현재 대응권자만 `abilityResponse`의 `counter` 또는 `pass`를 선택한다. 다른 일반 행동·상대 패 열람·진화 비용 열람은 잠근다. 항복은 허용한다.

라이징 윈드 걸은 위 **몬스터5종**과 기존 몬스터 카운터3종의 마지막 상대 효과만 무효화한다. **일체화2종**, 주문, 소환 자체는 대상이 아니다. 윈드 걸에 다른 윈드 걸로 대응하면 후발 선언부터 해결한다. 스톰블레이거·블래스트 보이·디텍티브 매치는 이 필드 발동 창에서 몬스터 효과를 주문으로 취급하여 무효화할 수 없다.

**확정 공통 규칙을 보존:** `PRODUCT_VISION_AND_RULES.md`의 기본 효과 횟수는 특례가 없으면 동일 카드/효과 자기 턴1회이다. 카드 문구에 횟수가 없다는 이유로 크래쉬볼티지를 무제한으로 바꾸지 않는다. 이번7종은 모두 기존 자기 턴1회를 유지하며, 무효화되어도 그 턴 사용을 소비한다. 필드 무효화3종의 재소환 재사용과 스톰블레이거의 같은 실제 카드 주문/소환 합계 게임당1회는 변하지 않는다.

## 해결·실패·영역 이동

- 무효화되거나 불발되어도 지불한 패/공격권과 선언 횟수는 반환하지 않는다. 사용 금지·대상 오류·비용 부족은 선언 전 거부한다.
- 소스 카드 ID·영역·조종자·영역 세대와 선택 대상의 영역 세대를 기록한다. 소스가 이탈 후 같은 UID로 돌아오거나 조종자가 바뀌면 이전 효과는 불발한다. 무효 상태 역시 재검사한다.
- 선택 대상 소실/재진입·조종권 변경은 불발, 탈취의 빈 칸이 사라져도 불발한다. 검색은 선언 시 정한 카드 종류를 해결 시 자기 영역에서 다시 찾는다. 이미 패로 이동해 검색 대상이 없어졌으면 불발한다.
- 사랑 도둑은 해결할 수 있을 때만 한 번 굴린다. 카이저는 R29에 따라 동결/공격 금지 중에도 남은 공격권을 지불할 수 있다.
- 도둑 M은 조건 취급 ATK가 아닌 실제 ATK(활성 마검 배율 포함)를 사용한다. 크래쉬볼티지 파괴는 원래 소스를 전달하여 마검 다음 자기 턴 배율 및 기존 파괴 유발을 유지한다.
- 선언·해결 예외 시 대기 상태/스택/비용을 원자적으로 복원한다. HTTP 버전·권한 검사와 저장 트랜잭션도 유지한다. 공개 응답은 내부 실행 계획·숨긴 검색 카드 UID·상대 손패를 내보내지 않는다.

## 최신 사용자 명확화 반영 — 실제 카드마다 독립된 횟수

동일한 효과라도 카드가 다르면 별개로 발동한다. 기존 `players[].abilityUsed[cardId]` 및 퓨전 업 `players[].effectUsage[cardId:effectNumber]`는 동일 카탈로그 ID의 다른 실제 카드까지 막았다. 이제 **units[UID].effectUsage[cardId:effectNumber]**로 기록한다. 필드 발동13종·AI 후보와 퓨전 업의 퓨전1번/묘지회수2번을 모두 변경했다. 효과 번호 간 독립 제한은 그대로다. 일반 카드 사용 기록은 이동/조종권 변경/재접속으로 초기화하지 않는다. 윈드 걸 등 별도 재소환 특례와 스톰블레이거 게임당 기록은 독립 상태로 유지한다.

구 저장은 시작할 때 식별 가능한 단일 실제 카드 또는 저장된 발동 소스에만 이전 기록을 귀속한다. **동일 ID 카드가 여러 장인데 옛 저장에 소스 UID가 없으면 어느 카드가 사용했는지 복구할 수 없다.** 해당 턴 기록을 `legacyEffectUsageUnresolved`에 보존하고 모든 카드에 일괄 적용하지 않는다. 이 경우 과거 사용 카드의 추가 발동을 완전히 차단할 수 없다는 이전 저장 형식의 한계가 있다. 새 선언부터는 UID로 정확히 기록한다. 원래의 전역 제한을 새 카드들에 복사하지 않는다.

`tests/physical-effect-usage.test.mjs`: 같은 카드2장 독립 발동, 동일 문구의 다른 카드, 같은 UID 이동/복원 후 중복 거절, 퓨전 업2장의 1/2번 독립 기록, AI가 미사용 복사본 선택, 구 저장 단일 귀속·모호한 기록 보존. `tests/recovery-api.test.mjs`는 실제 HTTP 및 재시작 후 UID별 기록을 확인한다.

**공유 예외:** 사용자 최신 확정대로 원소의 마법사4종 COC-32-001~004의 1번 효과는 합쳐 턴당1회이다. 2번 효과는 별개이며, 이 교체 소환은 후속 배치에서 추가했으며 위7종과 별도다. **사용자 추가 확정: 플레이어별로 4종 합계1회**, 상대 플레이어와 횟수를 공유하지 않는다. 교체 소환 실행은 [후속 명세](ELEMENTAL_REPLACEMENT_SUMMONS.md)에 연결했다.

원소4종의 공유 횟수 정책은 `effect-usage.mjs`에 등록했다. `physical-effect-usage.test.mjs`는 4종 각각을 선사용한 경우의 나머지3종·동일 카드 복사본 제한, 상대 플레이어 독립, 2번 효과 제외, JSON 복원·턴 변경을 검사한다. **사용 기록 정책 테스트이며 교체 소환 실제 실행 증거가 아니다.** 효과 커버리지에 4종을 구현 완료로 추가하지 않는다.

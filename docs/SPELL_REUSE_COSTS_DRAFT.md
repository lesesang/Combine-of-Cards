## 조건·비용·원본 구분

`planReusedSpellActivation`은 원본 주문의 사전검사를 **실제 재사용 실행자 UID**와 연결한다. 새 물리 카드를 만들거나 실행자의 카드ID를 바꿔 속이지 않는다. 원본 식별과 비용 계획을 JSON에 저장한다. 원본 사용 조건, 비용 후보, 대상, 빈 칸을 모두 검사한 뒤 실행자 사용 횟수와 원본 비용을 소비한다. 비용은 상대 대응 전에 한 번 지불하고 무효/대상 소실에도 반환하지 않는다. 사전검사 실패는 횟수를 소비하지 않으며, 선언 중 오류는 방 전체 스냅샷으로 되돌린다.

BLOCK은 실행자인 하우스 파티 자신을 버리는 비용으로 중복 사용할 수 없다. 시기는 실제 자기 필드 제물1장을 지정하며 기존 합계200 조건을 사용한다. 토큰 제물은 기존 R05 릴리스 경로에 전달한다. FLASH는 HP200을 지불한 뒤 생존해야 하고 빈 필드가 필요하다. 클로의 200은 원문대로 피해이므로 치명적일 수 있으며, 비용/드로우 리로드로 대전이 끝나면 새 대응을 만들지 않는다.

발동 조건은 선언 때 검사하고 해결 때 비용을 다시 지불하지 않는다. 대상은 기존 UID/조종권/체류 세대를 재검사한다. 드레고닉 브레스의 모드도 선언 스냅샷으로 고정한다. 필요한 값만 저장해 대상 없는 주문에 보낸 불필요한 대상·비용 필드가 처리를 바꾸지 못한다. 재사용은 원본이 실제로 다시 사용됐다는 기록을 만들지 않는다.

**개발자 해석:** 아젤리아/유리카/하우스 파티에 조건 무시 문구가 없으므로 원본의 조건과 비용을 유지했다. 아젤리아가 파라오 전용 주문을 과거 사용 이력만으로 쓰는 식의 조건 우회는 허용하지 않는다. 원죄의 공식 확정인 조건 내 비용 무시를 이 세 카드에 확대하지 않는다. 새 사용자 확정으로 취급하지 않는다. 자기 사용 이력/현재 보드 참조, 실행자별 횟수와 수치 다이스의 임시100 적용은 이전 묶음 그대로다.

## 검색과 일반 주문도 함께 수정

- 재사용 검색5종은 상대 대응을 통과한 뒤 기존 `pendingDeckSearch`로 이어진다. 후보는 선택권자에게만 공개하고 덱 순서를 숨기며, 고른 물리 카드만 공개 후 패로 이동한다. AI도 같은 선택 API를 사용한다. 원본 주문 실물의 현재 영역이나 카드 소유자를 검색 실행자로 착각하지 않는다.
- 조달책19-004의 일반 사용도 덱에서 첫 몬스터를 강제 선택하던 처리를 없애고 검색 선택으로 연결했다. “몬스터를 하나 뽑는다”를 덱 검색으로 해석한 개발자 결정이다. 해당 덱의 전개 선택을 보존하며 새로운 무작위 효과를 만들지 않는다.
- 포식의 주문07-003·포식자의 선별07-010은 원문 `conditions`의 상대1드로우를 선언 비용으로 옮겼다. 기존에는 무효화되면 드로우까지 취소됐다. 포식자의 만찬과 같은 비용 경로를 사용하며 무효화 후에도 드로우는 유지한다. 자가포식07-011은 B1 원문이 “효과가 해결되면”이므로 드로우를 선지불로 옮기지 않았다. 그 드로우로 대전이 끝난 뒤 회복/강화를 계속하지 않도록 했다.
- 공상 마도 필살 파동은 사전검사한5장 조건을 해결 때 자기 자신을 더해 다시 판정하지 않는다. 재사용 실행은 원소 주문 사용 장수를 가짜로 증가시키지 않는다.

## PvP·AI·저장

재사용 창에 원본 조건/효과, 브레스 모드, BLOCK 패 비용, 시기 제물을 추가했다. HP 비용과 자해는 원문을 표시하고 서버에서 처리한다. 지원 목록은 조건까지 현재 합법이라는 뜻은 아니며 서버가 선언 때 다시 판단한다.

AI는 원본 모드·합법 대상·자기 패/필드 비용 조합을 같은 사전검사에 통과시킨다. 비용만으로 즉시 패배하는 후보와 검색 후보가 없는 효과를 제외한다. 공개 보드/자신에게 허용된 정보만 사용한다. 전략 점수나 난이도별 승률 품질은 검증하지 않았다.

새 비용/모드 상태는 JSON 데이터다. D1 연결이나 동시 쓰기/CAS 구현은 없고, 개인 Cloudflare D1 계획은 유지한다. 이번 초안 배너는 `beta.18-draft`다.

## 미완료 및 후속 일괄 검증

53종은 기존 기본 효과 경로의 재사용 등록이며 모든 지속/동시 처리까지 인증한 수치가 아니다. 원죄 복사, 진화/퓨전/소환·원본 회수·몬스터화·실물 장착·재귀 재사용, 상대 패 공개 선택은 이 목록에 추가하지 않았다. 미연결 자동 부활·전체 동시 파괴/리로드·범용 체인 삽입도 남는다. 카탈로그 텍스트와 수치는 변경하지 않았다.

후속 검증 항목: 53개 재사용 기본 조항, 합법/불법 조건과 비용 부족·중복 실행자, 비용 선지불/무효/치명적 리로드, 원자적 롤백, 원소 이름 별칭, 모드·UID·대상 재진입, 5개 검색의 비공개/빈 후보/재접속, 하우스 파티 원본과 비용 분리, 다이스100과1d5/코인 구분, 정상 주문의 드로우 비용/조달책 선택, HTTP 버전 충돌, AI3난이도. 기존 즉시 선택/드로우 테스트를 새 선언 절차로 갱신하고 Node tests·Verify TCG beta를 함께 통과하기 전 병합하지 않는다.

다음은 별도 재사용 후속 처리(소환/진화/원본 이동)와 원죄의 스냅샷·제한 분리, 미연결 부활 사건 및 무기 장착·기간이다.

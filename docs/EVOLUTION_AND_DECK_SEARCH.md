모든 주문은 자기 MAIN에서 사용한다. 서버가 비용·소스·조건을 선검사하고 주문과 비용을 묘지로 이동한 뒤 상대 대응 창을 연다. 스톰블레이거 무효화 또는 소스 소실에도 이미 지불한 비용은 반환하지 않는다. 내부 처리·저장 실패는 HTTP 트랜잭션이 비용/사용 기록/버전/디스크를 복구한다.

진화는 선언한 일체화 UID·이전 카드 ID·영역 이동 세대를 고정한다. 대응 중 소스 이탈 후 같은 UID가 재진입해도 불발한다. 해결 시 UID·소유자·공격 횟수·강화·독립 마검/플레이어 강화 기록을 유지하고 새 기본값만 교체한다. 일체화 HP는 플레이어 HP이므로 유닛의 null HP를 0으로 바꾸지 않는다. 이미 구현돼 있던 유리카 진입 회복을 실제 진화 경로에 연결했다.

검색은 대응이 끝난 뒤 현재 자기 덱의 후보를 카드 ID 순으로 제시한다. 발동자만 후보를 볼 수 있으며 상대는 대기 상태만 받는다. 선택은 서버가 현재 영역·조건을 다시 검사한 UID로 수행하고 가져온 카드만 공개한다. 선택하지 않은 덱의 순서는 유지하며 원래 덱 순서를 후보 순서로 노출하지 않는다. 후보가 없으면 종료하고 항복/승패 시 대기를 제거한다. `COC-19-004 조달책`의 “몬스터를 하나 뽑습니다” 문구는 이번 명시적 선택 묶음에 넣지 않았다.

PvP와 AI는 같은 행동 검증을 사용한다. 하 AI는 정렬된 합법 후보 중 하나, 중/상 AI는 합법 후보의 인쇄 ATK를 기준으로 선택한다. 자연 비용도 자기 덱 합법 후보에서만 선택한다. 상대 비공개 정보를 평가 입력으로 추가하지 않았다.

# 원소 드래곤 이름·2번 효과와 추가 공격 — 2026-10-15

기준 main `42cb55a`(PR #73). 원소 덱15장의 플레이 카탈로그와 B1 수정 이력을 대조했다. 새 발동 오션·테라2종, 드래곤4종의 규칙상 이름, 플레임·볼케이노의 전투 추가 공격을 묶어 구현·보완한다. 원문·수치·덱 구성은 변경하지 않는다. 부재한 정본을 생성하지 않는다.

플레임·볼케이노2번은 기존 확정 공통 기본값인 **실물UID/개별 효과 자기 턴1회**다. 다른 실물 카드는 각각 사용하고, 플레임1번의 플레이어별 공유 제한과 독립이다. 카이저 등 다른 효과의 추가 공격이 있어도 +1을 더하며, 일반 영역 이탈 시 추가 공격 부여는 초기화하지만 이미 사용한 효과 횟수는 초기화하지 않는다. 조종권 이동만으로 추가 공격 부여를 삭제하지 않는다.

## 발견한 충돌과 개발자 결정

- 예전 조건은 이름에 ‘워터/윈드/랜드/플레임’만 포함되면 통과했다. 라이드 머신·F=HERO·카툰 등 무관한 동명 일부 문자열이 조건을 충족하는 오류를 막고 지정 마법사 또는 규칙상 같은 이름인 드래곤만 허용한다.
- ‘룰상 취급’은 필드 효과 복사와 구분한다. 원소 교체 후보/공유 사용 그룹은 기존 물리 마법사4종만 유지한다. 드래곤은 마법사로 둔갑하거나 다른 원소의 효과를 얻지 않는다. 같은 이름의 웨이크업 소재는 허용하지만 필요한 엑스트라 실물과 주문·빈 칸은 여전히 필요하다.
- 오션의 부등식은 선언·해결 양쪽에서 검사한다. ‘현재 실제 공격력’은 마검 배율을 포함하며 실제ATK와 조건 취급ATK를 혼동하지 않는다.
- 테라 체류 이력은 `dragonResidence={ownTurnStarts,lastTurnNumber}` JSON으로 저장한다. 필드→필드 조종권 이동은 체류 유지, 손패/묘지/덱/제외 이탈은 초기화한다. 효과 무효 중에도 시간은 진행한다. 같은 턴 시작의 중복 처리는 계수하지 않는다. 이전 저장에 이력이 없으면 과거 체류를 추정하지 않고 로드 이후 실제 턴 시작부터 센다.
- 웨이크업이 파괴 면역 소재를 남긴 채 소환하던 비용 검증 누락도 수정했다. 일반 마법사·규칙 이름 드래곤 모두 파괴 불가능한 비용은 사전 거부하며 패 주문/엑스트라/횟수를 변경하지 않는다.
- 플레임 비교는 전투 해결 직전 양쪽 실제ATK 스냅샷이다. 공격 상대의 피해 면역과 별개다. 볼케이노는 실제 파괴 여부를 확인한다. 종전 추가 공격 변수 자체를 사용 횟수로 삼던 구현을 UID/효과2 기록으로 교정한다.

이 해석은 사용자가 위임한 개발자 정비다. 새로운 개별 사용자 확정으로 표기하지 않는다. 기존17공식재정·마검·자의적 장착 해제 금지·간드레이 자기 제외·진화·카운터 재소환/게임 제한·원소 공유1번 제한은 보존한다.

## 남은 작업과 다음 순서

1. 워터2번 공격 선언 반격, 랜드2번 두 번째 턴 시작의 ATK/HP 교환을 공통 유발·선언 순서·상대 대응에 연결.

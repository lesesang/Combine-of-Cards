# 원소의 마법사 4종 교체 소환 — 2026-10-15

COC-32-001~004의 **1번 효과**를 서버/PvP/AI에 연결했다. 부분 지원163 / 미지원90 / 기본1, 효과 증거69건(66장), 필드 발동17종 중 대응11종(몬스터9·일체화2)이다. 네 카드의 모든 효과 또는 전 카드 자동화를 완료한 것은 아니다.

## 판정과 덱 의도

원소 덱15장의 현재 카탈로그를 함께 검토했다. 네 마법사의 형태 교체 → 대응 원소 주문 → 웨이크업으로 드래곤 전환 → 인피니티의 3소재 마무리라는 흐름을 보존한다. 플레임의 전투 연속성, 워터의 방어, 윈드의 직접 피해, 랜드의 체류 보상을 삭제하거나 수치를 조정하지 않았다.

- **기존 사용자 확정:** 플레이어별로 4종의 1번 효과 합계 턴당1회. 상대 플레이어/2번 효과와 별개다. 재소환해도 이미 소비한 공유 횟수를 복구하지 않는다.
- **신규 사용자 확정:** 패·덱·묘지에서 시도한 원소 교체 소환이 무효화되면 선택 카드는 **소환하려던 원래 영역에 유지**. 이미 지불한 비용은 반환하지 않는다. 일반 패 소환 전부에 이 결정을 임의 확장하지 않는다.
- **사용자 위임에 따른 개발 재정/문구 정리:** 자신 파괴는 선언 비용, 소환 카드 선택은 효과 해결 시점이다. 자기 패·덱·묘지에서 골라야 하며 비용으로 파괴한 원본도 가능하다. 공유1회가 반복을 제한하므로 임의의 ‘다른 이름만’ 제약은 넣지 않는다.
- 원문의 패 주문 조건은 소환 조건으로 유지한다. 조건 무시 문구를 새로 만들지 않는다. 드래곤4종은 규칙상 마법사로 취급되지만 전용 웨이크업 소환 조건을 교체 효과로 우회하지 않는다.
- [문구 패치 이력](card-patches.json)은 이전 **플레이 카탈로그**의 카드 객체와 새 1번 문장을 보존한다. 부재한 v1.3 원본 문서를 재구성한 자료가 아니다.

## 처리 단계

1. 자기 MAIN 또는 상대 턴의 빈 시점/공격 대응에서 필드 원소4종의 효과를 선언한다. 필드 조종자, 효과 무효 상태, 자기 파괴 면역, 공유 횟수, 합법 후보와 패 주문 조건을 비용 전에 검사한다.
2. 자기 파괴/공유 횟수 선지불. 원소유자의 묘지로 이동한다. 첫 파괴 회복이 여럿이면 기존 현재 턴 우선 선언 순서/LIFO 선택을 마친 다음 효과 대응으로 진행한다. 자기 비용 소스 이탈 예외를 적용한다.
3. 상대 라이징 윈드 걸이 **몬스터 효과**를 무효화하거나 pass한다. 스톰블레이거는 이 단계의 몬스터 효과에 대응하지 못한다. 윈드 걸에 다른 윈드 걸로 후발 대응하는 기존 LIFO를 유지한다.
4. 효과가 살아 있으면 발동자만 패·덱·묘지 후보를 보고 선택한다. 상대에게 후보 UID·덱 순서·미선택 패를 보내지 않는다. 소환 대상 이름은 소환 선언 시 공개한다.
5. **소환 대응 창**에서 스톰블레이거가 게임당 공유1회 소환 무효화 또는 pass한다. 윈드 걸은 소환 자체를 무효화하지 못한다. 무효 시 대상은 원래 영역에 남는다.
6. 합법 위치·소환 조건·빈 칸을 다시 검사하여 필드로 이동한다. 조건 소실은 비용 반환 없는 불발이다. 대응 중 다른 일반 행동/비공개 조회는 차단하며 모든 단계는 JSON 저장/재시작된다.

공격받던 카드가 자기 비용으로 떠나면 R21대로 공격자는 대상을 재선택한다. 같은 UID를 다시 소환해도 과거 공격을 바로 적용하지 않는다. 재선택 전에 `defend`를 보내 우회하는 요청도 거절한다. 공격 횟수는 추가로 지불하지 않는다.

## AI와 검증

세 난이도 모두 동일 서버 행동/권한/선택 검사를 사용한다. 상대 공격의 대상인 원소 마법사는 교체 대응을 고려한다. 쉬움은 합법 후보 무작위, 보통은 공격력, 어려움은 상대 턴에 체력도 평가한다. 자기 턴에는 더 강한 형태/부상 회복을 고려하되, 현재 형태에 대응하는 손패 주문과 웨이크업 소환 기회를 먼저 보존한다. 전 카드 최적 전략 인증은 아니다.

- `tests/elemental-replacement.test.mjs`: 4종×3영역, 두 무효화 단계, 비용/면역/조건, 같은 UID 복귀, 양쪽 플레이어/효과 번호, 공격 재선택, 동시 회복, 비용 롤백, 3난이도.
- `tests/elemental-replacement-api.test.mjs`: 4종×3영역×성공/효과 무효/소환 무효 36개 방, 각 단계 서버 재시작, 버전 충돌/위조 선택/권한 거절/비공개 정보/횟수 복구.
- `tests/ability-ui.test.mjs`: 상대 턴 버튼, 소유자 전용 선택, 자동 유발 순서 화면과 HTTP 제출. 실제 브라우저 시각 검수는 별도다.
- 카드 문구 패치 회귀는 수치·소속·소환 조건·2번 효과의 보존을 검사한다.

## 남은 범위와 다음 개발

- 다른 주문·필드 체인이 열려 있는 동안 원소 교체를 후발 삽입하는 범용 우선권은 미지원이다. 현재는 빈 시점/공격 대응에서 선언 가능하다. 상대 턴 UI 버튼이 있어도 턴 진행마다 상대 확인을 강제하는 완전한 우선권 프로토콜은 아니다.
- 워터/랜드 2번 및 드래곤의 규칙상 이름·개별 효과·인피니티 전 영역 제외는 별도 검토/구현 대상이다. 플레임/윈드의 기존 전투 효과도 전체 조건/무효화 인증이 아니다.
- 원소 외 남은 필드6종 대응, 일반/다른 효과/토큰 소환, 복사·전역 유발은 미완료다.
- 새 밸런스 검토는 [위임 정책과 덱별 검토 순서](CARD_REFINEMENT_POLICY.md)를 따르고, 원본·개정·실제 구현 상태를 구분한다.

## 재정 및 덱 의도

원죄의 기존 확정 효과 문장은 바꾸지 않는다. 「자신/이 카드」는 플레이어이며 원본 카드를 소모하지 않고 조건 항목 전체를 면제한다. 본문 비용·금지·명시적 사용 한도는 유지한다. 원죄 선언은 일체화 효과이므로 라이징 윈드 걸의 몬스터 전용 무효 범위를 넓히지 않는다. 별개의 원본 UID/효과는 독립이고, 능력을 등록했다고 원죄의 발동 횟수를 늘리지 않는다.

이번 사용자 위임에 따른 **개발자 해석**은 다음과 같다. 신규 사용자 개별 확정으로 표시하지 않는다.

- 현재 원죄에 사건/지속 능력을 등록하고, 유효한 같은 일체화 체류 동안 적용한다. 재복사로 같은 조항의 기록을 지우지 않는다. 재일체화는 새 체류이며 게임 한도와 복사 이력은 보존한다. 이탈·진화한 원죄 대신 다른 일체화에 능력을 몰래 이식하지 않는다.
- 소환형 사건은 등록 이후 **그 플레이어가 성공시킨 실제 몬스터 소환**을 관찰한다. 복사 직후 가상의 소환·피해·처치를 일으키지 않는다. 소환이 무효이면 원래 영역에 남고 복사 유발도 생기지 않는다. 오라클처럼 명시된 소환마다 발동 예외는 유지하고 나머지는 조항별 기존 제한을 적용한다.
- 원혼은 베리아 없는 플레이어 주체의 0 ATK/1 HP 설정, 랜드는 가변 ATK와 플레이어 HP 교환, 어나더는 같은 주체에게 +55를 두 번 적용하고 게임 사용 금지를 남긴다. 이 해석은 저주 덱의 선택형 복사와 위험/보상을 유지하려는 개정이며 AI는 원혼·어나더의 위험한 복사를 기본 후보에서 제외한다.
- 과거 파괴/밀/사용/손실 이력은 최초 복사 시점에 저장하고 이후 사건을 별도 기록한다. 상대 원본의 이전 자기 턴은 복사자의 자기 턴 기준으로 대응한다. 원본의 향후 이력을 재복사 때 다시 읽어 덮어쓰지 않는다. 소환 소재 기록이 없는 스톰 나이트에게 1장/2장 사건을 만들지 않는다.
- 만파식적의 회복/보호, 수은의 피해/파괴는 선택한 한 조항만 실행한다. 부활하는 버닝소울의 부활은 효과2다. 반면 트레이드의 반환·마검의 지불/벌칙은 종속 종료/유지 처리이므로 선행 효과에서 떼어내지 않는다. 망자의 분노는 조건란의 대상/3장 요건을 면제하되 실제 손실 이력만 피해 계산에 사용한다. 3장 미만이면 존재하는 값의 합을3으로 나누며 없는 이력을 만들지 않는다.
- 인형의 지속 공유는 같은 소스의 직접 대상+공유 대상을 합쳐 한 번만 적용한다. 다른 실물 소스는 독립이다. 연결이 끊기면 오라만 재계산하고 독립 부여 효과는 원래 수명을 따른다. 트레이드의 원래 두 교환은 우선하고 추가 공유/반환은3칸을 넘기지 않는 최대 조합을 사용하며 동률은 기록 순서로 고정한다.

무기3종의 실제 장착 계승은 기존 방패·검·투구 경로를 유지하며 이번에 같은 능력의 원죄 계승 경로를 추가했다. 자의적인 장착 해제는 허용하지 않는다. 실물 무기를 두 개로 복제해서 다른 호스트에 동시에 장착하지 않는다. 간드레이드래곤 자기 제외·17개 공식 재정·진화 기본 교체/강화 유지·마검 독립 배율·원소4종1번 플레이어별 공유1회는 변경하지 않았다.

`card-patches.json`의 `COPY-SHARING-2026-10-18-DRAFT`에 원죄·인형·스톰 나이트3장의 변경 전후/주석·덱 의도를 남겼다. 누락된 공식 DOCX/비교 JSON을 창작한 것이 아니다.

## 후속 일괄 검증·운영

검증 시에는 원본/복사자 이후 이력 독립, 같은/다른 UID·효과 번호, 원본/복사자의 재진입과 무효, 원죄 이후 소환/처치와 가상 사건 금지, 소재 비용/무효 원래 영역, 본문 비용 비환급, 비공개 선택·재접속·저장, 오라 중복/연결 종료/피해 보존, 양쪽 필드 가득 찬 교환·반환, 공격 금지와 R29 비용, 우선 대상/재선택, 마검·쿠퍼·기본 교체 조합을 회귀로 확인해야 한다. 아직 테스트를 작성하거나 실행하지 않았다.

다음 순서는 미지원 물리/정체성 조항 → 254장 조건/조항 전수 대조 → 누적 회귀·PvP·AI3난이도/24×24 → Node tests와 Verify TCG beta → main 병합이다. 부모 PR #75와 이 PR을 독립 검사할 수 있도록 순서대로 반영/재기준화한다. 스택된 PR의 현재 base에는 두 워크플로가 모두 실행되지 않으며, 테스트 단계에 main 기준으로 맞춘 정확한 최종 SHA에서 둘 다 통과해야 한다.

새 상태는 JSON 데이터로 저장한다. D1 어댑터·스키마·CAS/멱등 요청·구 방 버전 고정/이관·백업/복구·배포는 아직 남아 있다. 옛 저장의 없는 과거 사건이나 손상된 상태를 추정해 채우지 않는다.

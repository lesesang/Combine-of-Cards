# v1.3 카드 발동 전 검증 — 1차 구현 (베타)

이 문서는 게임 규칙의 *완전 자동 판정 인증서가 아니다*. `src/activation-rules.mjs`에는 v1.3 텍스트를 기준으로 조건을 구체적으로 검증하는 카드 ID **76개**가 명시되어 있다. 조건 검사가 가능해도 카드의 소환 시·지속·복사·대응 효과 자체는 미구현일 수 있으므로 카드 도감에서 해당 카드를 '완전 자동화'로 표시하면 안 된다.

## 구현한 검증 및 비용

- 지정 일체화가 필요한 주문/몬스터 및 특정 속성 필드 카드 수
- 상대 필드 존재 여부, 손패·덱 장수, 체력 상한, 첫 카드 사용 여부
- 금속·원소 카드 누적 사용 횟수 / 당턴 원소 주문 사용 횟수 / 자연 주문 누적 횟수
- F=HERO 유니버스: **자신의 필드 몬스터 2장**을 비용으로 선택하여 묘지에 이동시킨 뒤 소환 및 기존 소환 효과 해결
- 스톰블레이거 드래곤: 자신의 필드 몬스터 2장을 선택해 파괴한 뒤 일체화
- 간드레이드래곤: 자신을 제외한 모든 패를 묘지로 이동시킨 뒤 소환(자기 자신도 전부 파괴 효과의 대상)
- 츠쿠모가미 네코: 자신을 제외한 패를 모두 버린 뒤 소환
- 카툰 브레드코기 / G-머신 골드마그마의 추가 공격 금지 조건

**실제 플레이어 행동과 AI 판단은 같은 서버 검증에 의존해야 한다.** 현재는 서버 플레이 처리 전 검사가 붙었고, AI가 무조건 모든 합법적인 선택지를 만들어내도록 구현된 것은 아니다.

## 미확정 · 충돌 · 해석 필요한 항목

| 카드/상황 | 문제 | 권장 기준 (승인 전 임시 채택 금지) |
|---|---|---|
| F=HERO 용기의 패왕, 생명의 대장장이, 기타 `덱에 N장` 조건 | 원본 덱 구성의 수인지 사용 순간 남은 덱 장수인지 불분명 | **덱 구성 기준 / 실시간 덱 수 기준** 중 공식 확정 필요. 현 검사는 사용 순간 덱에 남은 장수 기준 |
| 연금술 공상 마도 필살 파동 | 당턴 5장 사용에 자신도 포함되는지 모호함 | '이 카드 외 5장' 또는 '이 카드를 포함하여 5장'으로 원문 확정. 현 사전검사는 이전 5장을 요구함 |
| 카툰 룩스 에터나 | 패에 있는 카드 2장을 '파괴'한다는 용어의 의미 및 타 플레이어 카드 포함 여부 | 사용할 카드는 자신이 보유/조종 중인 카드로 제한하고, 파괴 시 유발 효과 허용 범위를 명시 |
| 영매·저주 효과의 과거 파괴 횟수 | 과거 파괴 시점·원인·귀속 플레이어 기록이 부족 | 파괴 이벤트를 출처·컨트롤러·원래 소유자별로 별도 기록 |
| 지속 주문 | 주문을 묘지로 보낸 후 독립 효과의 유지·종료·무효화 우선순위 | 효과 식별자·발동한 카드·유효 기간·종료 사건을 별도 상태에 저장 |
| 주문/소환 중 상대 대응 | 기존 모델은 공격 선언 직후 대응에 집중 | 주문·소환·파괴 대응을 선언 이벤트 및 LIFO 해결 스택으로 확장 |
| AI 대전 중 수동 처리 불가 카드 | 플레이어가 선택지를 사용할 수 없는 경우가 남음 | 카드별 모든 유효 선택을 서버 명령으로 구조화하기 전까지 완전 자동 대전으로 표시하지 않음 |
| 기본 `몬스터` 소환 | 현재 명시 검증되지 않은 개별 특수 소환 조건이 남음 | 미검증 조건을 ID별 사전검사로 보강하고, 미확정 경우 서버에서 부적법 실행을 방지하도록 설계 |

## 검증 방법

```bash
npm test
npm run check:data
npm run check:coverage
```

새 카드 판정이 추가되면 해당 카드의 유효/무효 입력에 대한 서버 단위·통합 테스트를 필수로 추가한다. 다른 사용자에게 유리한 임의의 기본 동작을 추가하지 않는다.

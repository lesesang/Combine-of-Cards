소환 유발 **20종을 즉시 실행에서 공통 대응으로 이동**, 케미 회수를 새로 연결하고 기존 디텍티브 검색을 보완했다. 이는 22장 전체 효과의 완성 인증이 아니다. 새 유발 등록은 **33종(몬스터32·일체화1)**이며 주문76/대응68·필드22는 그대로다. 검증 없는 등록 수를 효과 증거91건/완전 인증0에 더하지 않았다.

## 공통 실행·선택·저장

- `src/summon-trigger-effects.mjs`에 효과 계열을 모으고 `triggered-effects.mjs`의 선언/순서 선택/상대 대응/해결을 재사용한다. 정상 패 소환과 현재 연결된 효과 소환, 해당 엑스트라 소환에서 같은 경로를 쓴다.
- 실제 UID/효과 번호/턴별 사용과 소스 필드 체류 세대·조종권·무효 상태를 검사한다. 22-015는 효과3으로 기록하여 다른 효과와 횟수를 공유하지 않는다.
- 렌의 조건에 있던 상대 드로우가 기존 코드에서 빠져 있었다. 사용 선언 시 비용으로 처리하며 소환/효과 무효화가 비용이나 해당 UID의 사용 횟수를 돌려주지 않는다. 서로 다른 렌은 독립이다.
- `deck-search.mjs`를 주문·몬스터 검색·케미 묘지 회수에 공유한다. 후보는 덱 순서와 무관하게 정렬하고 선택권자에게만 보여준다. 선택 완료 때 현재 영역·후보·소스 카드/체류 세대/조종권을 다시 확인하고 가져온 카드만 공개한다.
- 검색 선택이 끝나기 전에 보관 중인 다음 유발, 다음 묶음 소환, 턴 시작 후속 처리가 진행되지 않게 대기한다. 사람과 AI가 같은 선택 API를 사용한다. AI 케미 일체화 후보를 기존 합법성 검사 뒤 허용했다.
- 케미는 일체화 효과로 분류한다. 라이징 윈드 걸은 이 효과를 무효화할 수 없으며 등록된 상대 몬스터 효과만 대상으로 한다.
- 케미는 `usedCardsGame`의 실제 UID 이력만 참조한다. 그냥 버려진 주문은 회수 후보가 아니다. 엑스트라 소환에서 사용한 실제 퓨전 주문도 선언 때 기록한다. 주문 무효화는 이미 사용한 이력을 지우지 않는다. 과거 저장에 없는 사용 기록을 묘지/로그에서 만들어내지 않는다.
- 대기 상태는 JSON 데이터이며 개인 Cloudflare D1 이전 계획을 유지한다. D1 연결·마이그레이션·배포는 이번 범위가 아니다.

## 원문과의 차이 수정 및 위임된 개발자 해석

사용자 신규 확정이 아니라 기존 원문과 위임에 따른 구현 판단이다.

1. 스플래쉬 걸: 패 수는 소환 조건이다. 성공 소환 후 효과 해결 때 패 수를 다시 검사해 드로우를 취소하던 코드를 제거했다.
2. 스파클링오션: 원문은 상대 몬스터에 한정하지 않는다. 양쪽 필드에서 고르며 본래 ATK가 수치로 정해진 카드를 비교한다. 본래 ATK가 미정인 카드의 수치를 임의로 0이라고 만들지 않는다. 대상은 효과 대응 후 선택한다.
3. 카스테: 선택은 대응 후, 코인은 선택 후에 서버가 굴린다. 판정 결과를 미리 보고 대상을 바꾸지 못한다. 적이 없으면 선택/효과를 종료한다.
4. 케미: 자기 턴 시작에 자기 사용 이력·자기 소유·현재 자기 묘지의 실제 주문1장을 회수한다. 상대가 사용한 주문을 복제하거나 존재하지 않는 과거 기록으로 후보를 만들지 않는다.
5. 율리우스: 자기 턴 소환은 다음 상대 턴, 상대 턴 소환은 현재 상대 턴의 종료까지 금지한다. 상대 턴 소환으로 상대의 두 턴을 막던 연장 가능성을 제거했다.
6. 티라노: 소환 효과가 무효/횟수 소진/무효 상태이거나 덱이 비어 HP를 얻지 못했다면 체력 없는 무적 몬스터로 남기지 않고 HP0의 치명 상태로 파괴한다. 별도의 정상 HP가 이미 있으면 유지한다.
7. 명시적 소환 문구가 없는 기존 즉시 진입 효과의 발동 시점은 이번에는 기존 소환 시점을 유지했다. 무제한 MAIN 재발동으로 바꾸지 않았다. 사건형 유발은 앞선 초안과 같이 소환 사건이 상대 턴에 생겨도 실제 UID/개별 효과별 해당 턴1회를 적용한다.

## 남은 구현과 다음 묶음

- 베리아/스트로베리아의 **묘지 이동 효과 발동 사건**, 원죄/아젤리아/유리카/하우스 파티의 실제 효과 복사·재사용, 무기 장착/만료.
- 와이번 자해 비용, 스톰 나이트·팬니르 토큰/비용, 쌍둥이 복제, 아스클레피오스·이모탈 부활 등 아직 즉시 실행되는 소환/파괴 경로. 이번 새 유발 경로가 모든 토큰·자동 부활을 포괄하지 않는다.
- 전역 동시 드로우/리로드 승패·피해 방지 공통화, 일반 체인 중 새 효과 삽입·모든 유발의 같은 시점 우선순위. 양쪽 드로우는 기존의 자신→상대 순서를 유지하며 첫 드로우로 게임 종료 시 다음 드로우를 하지 않는다.
- 24×24 전체 대전·난이도 품질·생성 보고서 갱신·D1·운영 배포는 미완료다.

다음 구현도 카드 한 장 단위 절차를 반복하지 않고 사건/복사/장착 계열로 묶는다. 상세 명세는 이 문서처럼 묶음별 한 곳에 모으며 이슈는 영향을 받는 항목만 갱신한다.

## 후속 일괄 검증 목록 — 아직 실행하지 않음

기존 즉시 소환/검색/코인 기대 테스트를 실제 소환 pass → 유발 pass → 선택 흐름에 맞춰 갱신해야 한다. 렌의 비용/다른 UID/무효·재소환, 소스 이탈·재진입·조종권, 타이밍별 패 조건, 스파클링의 양쪽 필드/본래값/실제ATK, 매지션 효과3, 티라노 토큰·빈 덱·무효·횟수 소진, 코인 경계/재선택 방지, 케미 미사용/사용·무효 주문/구 저장/윈드 걸 제한, 여러 유발과 검색·묶음 소환 순서, HTTP 권한/버전·비공개·재시작 및 AI 세 난이도를 검증해야 한다. 이후 생성 보고서와 Node tests·Verify TCG beta를 통과하기 전 main에 병합하지 않는다.

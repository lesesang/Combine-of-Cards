# 엑스트라 덱 21종 자동 판정 — v1.3 (베타)

이 문서는 실제 서버 동작과 미지원 영역을 구분합니다. **21장 모두 소환 자격 검증 가능**은 **21장 모든 카드 효과 자동화**와 다릅니다.

## 구현된 범위

| 분류 | 카드 ID | 자동으로 확인하는 내용 |
|---|---|---|
| F=HERO 버디 5장 | COC-12-011 ~ 015 | 용기의 패왕 일체화, 지정 몬스터 2~3종 패/필드 소재 |
| 블랙 메탈 5장 | COC-22-011 ~ 015 | 블랙 메탈 몬스터 2/3/5장, 퓨전업/블랙 메탈 퓨전 업 |
| 지니어스 2장 | COC-26-011 ~ 012 | 게이머+카미, 저지먼트+디텍티브 및 퓨전업 |
| 슈페리얼 4장 | COC-27-011 ~ 014 | 슈페리얼 파이터와 지정 소재 및 퓨전업 |
| 드래곤 위저드 4장 | COC-32-011 ~ 014 | 웨이크업 드래곤!과 필드 해당 원소, 파괴 |
| 인피니티 1장 | COC-32-015 | 필드의 원소의 마법사/드래곤 위저드 중 서로 다른 3장 |

**서버가** 소재 장수, 물리적 카드 인스턴스 중복, 필드 영역, 소환 여유 공간, 주문 카드 보유 및 종류를 확인합니다.
소재 사용 시 일반 퓨전은 묘지로 보내고, 웨이크업은 파괴합니다. 웨이크업 드래곤! 주문은 해당 턴 종료 시 묘지에 있으면 패로 복귀합니다.
AI가 이 검증기를 이용해 가능한 소재 조합을 탐색하므로 불법 소환을 임의로 진행하지 않습니다.

## 추가 구현된 소환 시 효과

- F=HERO 버디 스파클링오션: 기본 공격력 조건을 만족하는 상대 필드 몬스터를 선택해 파괴합니다.
- 블랙 메탈 매지션: 자기 덱의 퓨전업 또는 블랙 메탈 퓨전 업을 검색합니다.

## 아직 완전 자동화되지 않은 부분

- 용기의 패왕과 일부 퓨전업 주문의 묘지 발동, 재사용, 상대의 대응을 처리하는 효과 스택
- 퓨전 몬스터의 지속/반응 효과 전부: 공격 제한, 전투 파괴 무효, 카운터, 턴당 효과 사용 횟수, 추가 공격, 게임에서 제외 등
- 상대 플레이어의 선택이 필요한 효과(오라클 슈페리얼 파이터의 양측 덱 맨 위 선택 등)
- 특정 소환 사건과 효과 무효화/복사/장착/제외의 연쇄처리 및 모든 카드 조합 테스트
- 언데드 퓨전업의 **묘지 → 덱 소재 반환** 방식. 이 자동 소환 경로는 현재 목록에 포함되지 않습니다.

## 판정 충돌 및 추가 검토 제안

1. **소재의 취급 몬스터 여부:** 「블랙 메탈 몬스터」에 블랙 메탈 퓨전 몬스터가 포함되는지, 기본 이름 판정 또는 카드군 속성 판정으로 명시할 것. 현재 구현은 블랙 메탈 이름을 가진 몬스터를 허용합니다.
2. **소환 자체에 대응 가능 여부:** 현재 소재를 소비하고 즉시 소환합니다. 대응 체인이 완성되면 소재 소비/소환 사이에 어떤 대응이 허용되는지 정의해야 합니다.
3. **웨이크업 드래곤! 이동 후 반환:** 턴 종료 전에 묘지에서 다른 영역으로 이동한 경우 되돌릴지 명시해야 합니다. 현재 구현은 묘지에 남아 있을 때만 패로 되돌립니다.
4. **스파클링오션 유효 대상 부재:** 조건을 만족하는 상대 몬스터가 없다면 소환만 성공하고 파괴 효과는 처리하지 않습니다.
5. **검증과 실행의 원자성:** HTTP 액션은 실행 오류 시 상태 스냅샷으로 되돌립니다. 서버 테스트는 별도 검증 함수를 직접 확인합니다.

추가 전환을 완료하기 전까지 사이트는 규칙 v1.3 기반 **베타**이며, 자동화 상태는 보수적으로 '일부 지원'입니다.

## 공통 가산 강화·회복

`src/stat-gains.mjs`에서 받는 카드의 현재 속성과 조종자/영역 보유자를 확인한다. 용왕11-003과 일체화한 양측 플레이어의 유효한 지속 효과는 용/드래곤 속성 수신자에게 각각 ×1.5, 상대 필드의 유효한 꽝철이11-005는 상대 플레이어와 그 카드에 각각 ×0.5를 적용한다. 이름에 ‘드래곤’이 있어도 원소 속성이면 용왕 대상이 아니다. 필드 밖 강화는 현재 보유자를 기준으로 하며, 일체화하지 않은 플레이어도 꽝철이의 반감을 받는다.

모든 배율을 곱한 뒤 **각 효과의 가산량마다 한 번 내림**한다. 용왕1장/상대 꽝철이1장이 있으면 기본+30은 floor(30×1.5×0.5)=22, 양측 용왕2장이면 기본+30은67이다. 다른 실제 카드의 오라는 각각 계산한 뒤 더한다. 한 카드의 개수 비례 효과는 개수로 기본 증가량을 만든 뒤 배율을 적용한다. 플레이어 공격력 영구 보상은 해결 시 계산해 저장하고 현재/이후 일체화에 한 번만 반영한다.

기본 능력치 초기화·값 설정/복사/교환·진화 기본값 교체·HP 비용·피해·리로드는 가산 강화가 아니다. **마검의 기본+100에는 수신자 배율을 적용하지만 지불30과 처치별 다음 자기 턴의 독립×2 규칙은 바꾸지 않는다.** 여러 마검의×2/×4/×8 등은 여전히 별도 배수 층이다. 합의 수동 판정의 직접 수치 조절은 사용자가 합의한 최종값으로 남긴다.

일회성 강화는 해결 당시 적용량을 저장한다. 이후 용왕·꽝철이 출입으로 과거 강화/회복을 소급 변경하지 않는다. 자가포식·뜨임질은 실제 적용량만 만료시 제거한다. 귀족의 영구 강화는 적용된 ATK/HP를 각각 저장하며 패/덱/묘지 복원 시 배율을 다시 적용하지 않는다. 이전 저장의 `noblePermanent`도 기존 수치 그대로 함께 복원한다.

지속 가산 층은 현재 소스/조종자/배율로 재계산한다. 토우·피라미드HP는 이전 지속 가산량과의 **차이만** 반영해 이미 받은 피해를 보존한다. 해제/무효로 현재HP가0이 되는 경우는 기존 서버 상태 정리에서 파괴한다. 장착값 원본과 게임 이력 원본은 배율로 덮어쓰지 않는다. 유닛 생성과 저장 로드/상태 갱신에서 현재 카드 속성을 갱신한다.

밀짚인형 공유가 연결된 경로는 확장된 수신자마다 해당 수신자의 배율을 한 번 적용한다. 지속 오라 자체를 밀짚인형 연결로 복제하는 경로는 아직 미구현이다. 파프니르의 기존 경로는 **새 보물이 추가될 때 증가분을 주는 방식**으로 남으며, 무효 중에는 새 강화가 생기지 않는다. 무효 해제 후 과거 미적용 보물을 소급 강화하거나 모든 보물 강화 이력을 지속 층으로 변환하는 기능까지 구현한 것은 아니다. 토큰/황금/반지의 전역 체인은 다음 묶음에서 별도로 다룬다.

## 용왕·오로치의 어택 시작 유발

MAIN에서 실제 ATTACK으로 들어갈 때 용왕11-003과 오로치11-006의 효과를 모아 기존 동시 유발 순서 선택·LIFO·상대 대응 경로에 넣는다. 어택 생략이나 MAIN 중 효과 공격은 이 사건을 만들지 않는다. 비용은 없으며 실물별1번 효과 사용을 선언에 기록한다. 각 실제 카드는 별개다.

- 용왕은 상대 플레이어와 해결 시 상대 필드 몬스터 전부에게 각각50 효과 피해를 준다. 일체화 효과이므로 윈드 걸의 몬스터 전용 무효 대상이 아니다.
- 오로치는 선언 시 저장한 이번 필드 체류의 **실행된 공격 횟수×80**을 같은 대상 범위에 준다. 공격 선언/재선택 취소는 제외하고 ATK0·피해 면역인 실제 공격은 센다. 효과가 무효인 동안의 실제 공격도 이력으로 센다. 이번 페이즈에 새로 한 공격은 다음 ATTACK 시작부터 반영된다. 윈드 걸이 무효화할 수 있는 몬스터 효과다.
- 소스의 UID·카드ID·조종자·체류 번호·현재 무효 상태·사건 턴/페이즈를 확인해 이탈/재진입한 새 소스로 해결하지 않는다. 필드를 떠난 오로치는 누적 공격0, 필드를 떠나지 않는 조종권 변경은 누적치를 보존한다. 조종권 변경 전 선언은 체류 번호가 달라져 불발한다.
- 선택 대상이 없는 전체 효과이며 해결 당시 상대 필드를 사용한다. 피해 면역과 밀짚인형의 기존 한 단계 피해 공유/중복 제거를 사용하고, 피해 후 파괴는 직접 파괴 선언으로 분류하지 않는다. 스핑크스가 두 효과를 직접 파괴 효과로 막지 않는다.

공통 PvP 대응 UI와 AI 카운터/순서 처리에 연결했다. 필드 카드에는 현재 가산 강화·회복 배율 및 오로치 누적 공격 수, 플레이어에는 해당 배율을 표시한다. 장착 UI는 현재 적용되는 무기 가산량을 표시한다. 마검/반지 로그는 기본량과 적용량을 구분한다. AI3난이도의 실제 판단 품질은 검증하지 않았다.

새 상태는 UID·숫자·일반 객체/배열만 사용해 기존 JSON 저장에 포함된다. 옛 저장에 없는 오로치 공격 이력은 로그에서 추측해 만들지 않고0부터 기록한다. 실제 D1 저장 어댑터/동시성/이관 작업은 별도다.

**자동 체인 전체 통합은 아니다.** 현재 마검의 강제 지불과 황금의 보물 증가는 기존 ATTACK 시작 경로에서 먼저 처리되고, 이어 이번 두 유발을 선언한다. 마검·황금·용왕·오로치 사이의 모든 동시 사건을 단일 전역 순서 선택으로 합치는 작업과 토큰/반지의 즉시 해결 경로는 남는다.

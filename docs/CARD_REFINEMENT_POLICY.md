# 덱 의도를 보존하는 재정·카드 정비 — 2026-10-15

사용자가 “원문을 보고 애매한 재정이나 지나치게 사기적인 효과 등은 네가 알아서 패치”, “그 덱 전체의 흐름과 창작 의도”를 해치지 않는 범위에서 “모든 카드와 재정”을 다듬도록 위임했다. 앞으로의 개발 범위에 **전 카드 재정/밸런스 정비**를 포함한다. 반복 승인 질문을 전제로 진행하지 않는다.

기존17재정·마검·장착·간드레이드래곤·진화·개별 횟수 등 사용자 확정은 현재 기준선이다. 구현 편의만으로 뒤집지 않는다. 위임 범위에서 변경이 필요하면 기존 판정/개정 판정/구체적인 충돌이나 악용 사례/덱의 주요 연계 보존/회귀 검증을 함께 기록한다. 개발자가 결정한 새 재정을 ‘사용자가 개별 확정했다’고 쓰지 않는다.

## 작업 단위

1. 한 카드만 보지 않고 해당 덱의 메인·엑스트라·생성 카드와 조건/비용/회수/승리 수단을 먼저 읽는다. 창작 의도는 명시 자료와 카드 연계에서 확인한 사실, 개발자의 해석을 구분한다.
2. 먼저 문구·시점·대상·횟수를 일관되게 만든다. 수치나 효과의 약화/강화는 무한 반복·대응 불가능한 확정 승리·과도한 자원 차이의 구체적 재현을 근거로 한다. 큰 숫자만으로 사기라고 단정하지 않는다.
3. 현재 카탈로그의 변경 전/후와 이유를 `card-patches.json`에 기록하고 UI 원문/엔진/효과 증거를 같은 PR에서 맞춘다. 부재한 정본 원본을 창작하지 않는다.
4. 정상 연계와 악용 방지·비용 실패·무효화·AI·복구 회귀를 검증한다. 별도 브랜치/PR의 최종 두 CI 성공 후 병합하고 main CI 및 이슈를 갱신한다.
5. 24덱/254장 전수 검토, 576 대전 검증, 전체 자동화 및 밸런스 인증은 각기 별개이며 완료한 범위만 기록한다.

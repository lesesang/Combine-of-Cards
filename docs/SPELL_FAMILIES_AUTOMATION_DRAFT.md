# 주문15종 실행 경로·G-툴·재단 묶음 — 2026-10-16

draft PR #75의 **구현 초안**이다. 사용자 요청에 따라 테스트 작성/실행·문법 검사·CI를 보류했다. 아래는 작성한 코드와 개발자 해석이지 전 효과 완료 인증이 아니다. main PR #74의 과거 테스트/생성 보고서는 이 변경의 검증 증거로 사용하지 않는다.

## 범위

## 공통 처리와 파일

- `protection-auras.mjs`: 독립 보호 JSON, 피해/직접 파괴 차단, ATTACK/END 만료, 지속HP 증감과 지속ATK 산출. 손상HP를 초기화하지 않고 층의 차액만 적용한다.
- `history-spells.mjs`: 덱 위 이동 수, 최고ATK/최근 손실/행위자 이력, 일정표 검색 후 강제 END 예약. 회수된 원본의 사용 횟수를 실물UID로 유지한다.
- `trade-separation.mjs`: 상대 선택을 기존 `pendingDeckSearch` 잠금에 연결, 교환/반환 JSON, 양측 분리 피해. 재진입한 대상을 다시 잡지 않는다.
- `black-metal-change.mjs`/`extra-summons.mjs`: 묘지 소재 레시피, 인쇄 영역 반환, 비공개 덱/엑스트라 후보와 개별 소환 대응.
- `monsterized-spells.mjs`: G-툴 및 재단 생성/실물 소환 계획. 패·덱·묘지·엑스트라의 동일한 부활 대기열을 재사용한다.
- 서버/UI/AI: 보호/피라미드 표시, 묘지 퓨전 소재, 상대 교환 선택, 카툰 연속 선택, 블랙 메탈 후보 선택, G-툴/재단 발동 선택. 서버가 준 공격 한도를 UI가 사용한다. AI도 같은 조건·비용·선택 실행자를 거친다.

모든 새 대기 상태는 JSON 값이다. 이는 미래 D1 어댑터에 필요한 성질일 뿐 D1 연결·동시성/트랜잭션 검증 완료를 뜻하지 않는다.

## 위임받은 개발자 해석·밸런스 패치

사용자의 “해석 필요한 부분은 밸런스 보고 알아서” 권한을 적용했다. 20장의 런타임 텍스트 전후와 이유를 `card-patches.json`의 `SPELL-FAMILIES-2026-10-16-DRAFT`에 기록했다. 원본은 d2f1a77 런타임 카탈로그이며, 저장소에 없는 정본 DOCX/비교 JSON을 생성하거나 그 문구를 인용한 것으로 표시하지 않는다.

- 강제 분리는 피해 수신자가 불명확했다. 스톰 판본의 공격 판정→분리 순서를 유지하고 각 일체화 플레이어의 반동 피해로 명시했다. 슈페리얼 판본도 통일했다. 확정된 별도 공격 대상 재정을 뒤집은 것으로 취급하지 않는다.
- 재단은 저주/악마 덱의 초동 확보를 위해 첫 자기DRAW에 패/덱에서 자동 발동하는 것으로 명시했다. 흡혈 공작/밀짚인형은 실제 패·덱·묘지 카드, 나머지4종은 기존 생성 카드 정의를 사용한다. 공작180/귀족300 체력 비용은 **이번 개발자 개정값**이며 원문에 있었다고 주장하지 않는다. 인형30/임프60/가고일150/몽마200은 기존 수치를 유지한다. 생성체 복제 회복/공짜 재사용 방지를 위해 소환 무효된 생성체는 폐기한다.
- 피라미드의 후발 적용과 실물별 갱신, 블랙 메탈의 같은 실물 자기 교체 금지, 만파식적 각 조종자의 만료, 분노의 필드 체류 최고ATK를 명시했다. 실전 승률로 검증한 밸런스 수치가 아니다.
- 확정17재정·최신 마검/무한 곱·자의적 장착 해제 금지·간드레이 자기 제외·진화 기본값/원형 복원·윈드 걸 범위·개별 횟수/원소4종 공유 예외는 변경하지 않았다.

## 남은 기능과 검증 대기

1. **재단 소환은 피소환 몬스터의 모든 효과 완성을 뜻하지 않는다.** 밀짚인형 공유 적용, 몽마의 코인 봉쇄/유인, 나락의 귀족 영구 강화/악마 오라가 남는다. 공작 전투 흡혈/가고일 기본 도발은 기존 부분 경로를 사용한다. 원죄 진입 조건·독립 복사/과거 스냅샷도 별도 미완료다.
2. 미라 대장군·피라미드를 연결했지만 호루스/용왕/꽝철이 등 모든 지속 수치 합성은 끝나지 않았다. 신규 보호도 모든 과거 직접HP 변경 경로를 전수 감사한 상태가 아니다. 피해/비용/설정의 남은 호출 경로를 구분해야 한다.
3. 언데드 퓨전은 기존 소환 대응 경로를 사용한다. 별도 퓨전 주문 발동 대응과 소환 대응을 모두 분리하는 전역 체인 확장은 남는다. 토큰/파프니르/카툰 사망의 기존 즉시 처리도 남는다.
4. 새 분노/심판 이력은 저장소에 실제 기록된 사건만 사용한다. 업데이트 전에 진행한 방의 누락된 과거 수치/사건을 완전 복원할 수 없다. 새 게임과 기존 저장의 마이그레이션 정책·정합성 검증이 필요하다.
5. 모든 카드의 조건/효과별 추적, 중첩 대응/선택/동시 사건, PvP·AI3난이도/24×24, 재접속·비공개 정보·동시 요청, D1 운영 이관과 배포가 남는다.

후속 일괄 검증에는 타깃 재진입/조종권 교환/양측 가득 참/한쪽 반환 불가, 보호와 HP지불/리로드/스킵, 각 소환 무효와 원래 영역·비용, 생성체 삭제 시 장착/사망, 첫 카드/강제 END 유발, UI/AI의 동일 선택, 오래된 저장, 선언·선택 중 복구를 포함한다. 현재는 테스트/문법 검사/CI **미실행**이며 main에 병합하지 않는다.

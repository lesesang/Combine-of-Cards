## 2. 기술 구조 변천과 현재 책임 분리

- **server.mjs**: 실제 게임 상태, 턴·드로우·리로드·기본 공격·동시 승패, 서버 API/인증, AI 루프, 지속/파괴 사건의 카드별 훅. 일부 단일 파일 조건문으로 효과가 직접 구현되어 있음.
- **src/automated-effects.mjs**: 일부 주문 ID별 실행 핸들러(**70개** 등록 기준).
- **src/activation-rules.mjs**: 카드 발동 조건/비용 사전 검사(80종 기준).
- **src/extra-summons.mjs**: 엑스트라 덱 **21종** 지정 소재/소환 자격; 전체 고유 효과를 증명하지 않음.
- **src/field-abilities.mjs**: 명시적 필드 발동 13종(beta.10).
- **src/effect-runtime.mjs**: 2026-10-13 추가한 독립 스택/지속 효과 처리 기반. 모든 일반 주문의 대응 창까지 연결되지는 않음.
- **src/dragon-gold.mjs / src/cartoon-land.mjs**: 복잡한 카드 트리거의 실제 부분 연동 예시.
- **src/automation-status.mjs**: 카드별 베타 지원 여부 표시(현재는 **완전 지원 상태 없음**).
- **public/app.js**, style, index: 도감·덱 선택·대전 UI, 승인·대상 선택, 지속 카운터 표시.
- **tests/**: 카드 ID 및 경계 상황 회귀 테스트. 대전 전체 조합에 대한 증명은 아님.

## 3. 추후 유지보수자가 알아야 할 역사적 오류

1. **덱 수 혼동**: 대화 중 27/25라는 중간 단계 수가 있었으나 최종은 **24**.
2. **자기 포함 전체 파괴**: PR #10 전에는 간드레이드래곤까지 파괴했다. 절대 되돌리지 말 것.
3. **보고서 상태 과소 집계**: PR #16 이전 수동 표기는 실제 코드 대비 35장 차이. 앞으로 문서 생성 스크립트와 실제 상태를 함께 검증.
4. **오래된 보고서**: docs/AUTOMATION_AND_RULINGS.md의 2026-10-12 자동 주문 57개, README 하단 일부 구버전/미지원 151개 언급은 **그 날짜의 역사적 기록**. 현재 상태를 뜻하지 않으므로 관련 문서 최신화 필요.
5. **카드 텍스트의 단순화 손실**: v1.3 정규화 중 블랙 메탈 퓨전 업 '공격 기회 사용 비용'이 빠졌다가 복원된 사례가 있음. 코드로 만들기 전 원문과 정본을 대조.
6. **CI 실패→수정 이력**: PR #14/#19 등 초기 CI가 실패했지만 오류를 수정하고 성공 상태에서 병합했다. 이전 실패 로그가 있다고 현재 main이 반드시 실패한다는 뜻은 아님.
7. **최신 CI 통과 ≠ 규칙 정답성 보장**: 대부분 테스트는 알려진 사례와 24개 AI 덱 스모크 검사로, 전 카드 효과와 모든 상호작용 테스트를 완성하지 못함.
8. **공개 배포 미완료**: Dockerfile·CI는 존재하지만 운영 DB/HTTPS 공개 서비스·재접속 복구·보안 검증은 추가 작업.

## 4. 이후 구현 기록 방식

새 기능마다 PR에 다음을 남긴다.

- 카드 ID와 원문 효과(또는 확정 재정 링크)
- 조건/비용/대상/타이밍/지속/실패의 실제 처리 내용
- 효과가 직접 지원되는가, 일부 지원인가, 단순 소재/조건만 검증되는가
- 유효·무효·역순 대응·동시 사건·AI/비공개·이동/종료에 대한 테스트
- 영향을 받은 지원 상태 수치, 코드 경로 및 문서 링크
- 해결된 판정과 여전히 공식 결정이 필요한 판정
- 배포 마이그레이션/보안 영향과 GitHub Actions 검사 상태

## R18 실제 공격력과 조건용 취급 공격력 분리 (PR #50)

- `src/combat-stats.mjs`에서 `actualAttack(unit)`와 `treatedAttackForCondition(unit)`를 별도 API로 분리. **블랙 메탈 매지션(COC-22-015)**의 실제 공격력과 일반 공격 다이스는 **50 / 1d50**, 명시된 조건 판정에 한하여 공격력을 **250으로 취급**한다. 공격력 강화로 실제 300이 되었다면 조건 판정은 300으로, 원래 실제 수치는 수정하지 않는다.
- 서버 실제 공격 다이스에 `actualAttack`을 적용하고, 조건 전용 함수는 일반 공격에 사용하지 않는다. 기본 공격력 소수 버림·음수 0 고정 유지.
- `tests/combat-stats-r18.test.mjs`에 전투·조건 값 분리 및 수치 경계 테스트. **블랙 메탈 체인지 주문 효과 전체는 아직 미지원**이므로 실제/취급 공격력 중 어떤 조건을 언제 비교하는지는 이후 개별 카드 구현·원본 검증 작업이 남아 있다.



## 2026-10-13 R15 장착 링크·이동 기반 (PR #51)

- `attachCard(r,cardId,hostId)`로 기존 카드 UID를 물리 영역에서 분리해 `attachmentHostId` / `host.attachments` 관계로 저장. 중복 영역 등록 및 장착 카드의 관계 해제 없는 독립 이동 차단.
- 장착 대상을 묘지·패·덱·제외로 이동하면 장착 카드도 **원래 소유자의 해당 영역으로 동반 이동**. 장착 대상의 필드 내 조종권 변경에서는 연결 유지. 파괴에 의한 이동, JSON 복구, 잘못된 입력 검증.
- **범위 제한:** 특정 카드 장착 발동·소환 3턴 후 제한·주기적 생명 비용·장착 해제 효과 및 전 카드 능력치 자동화는 미구현. 이 단계는 장착 시스템의 물리적 카드 상태 기반만 제공하며 완전 자동 플레이 기능으로 분류하지 않는다.



## 2026-10-13 R15 개별 장착 해제 기반 (PR #52)

- `detachCard(room, equipmentId, destination)`는 연결된 장착 카드 UID를 검사하고, 한 장만 장착 해제하여 원래 소유자의 묘지·패·덱·제외 영역으로 이동시킨다.

- `tests/attachment-lifecycle.test.mjs`에 복수 장착/JSON 복원/원소유권/이동 대상별 회귀 테스트를 추가했다.
- **제한:** 내부 효과 엔진 기반에 한정한다. 개별 카드의 사용 가능 시점·장착 3턴 제한·대상 선택 UI·효과 발동·턴 비용 및 생명을 먹는 마검 패배 자동화는 별도 작업. 장착 카드를 임의로 제거하는 새 자유 행동은 만들지 않았다.

# 카툰 랜드 파괴 연쇄 자동 판정 (v1.3)

> 2026-10-17 후속: [카툰 자동화 초안](CARTOON_DECK_AUTOMATION_DRAFT.md)에 공통 주문/소환 대응과 부모 재개를 작성했다. 아래 확정 순서는 유지하며, 이전 테스트 결과는 새 코드의 검증 증거가 아니다.

## 확정 규칙

1. 카툰 랜드(`COC-05-002`)는 사용 시 체력 100을 지불하고 필드에 0/1 몬스터 취급으로 남는다.
2. 카툰 랜드는 전투로 파괴되지 않는다. 그러나 주문·효과에 따른 파괴와 피해로 체력이 0이 되는 일반 사건은 전투 외 규칙에 따른다.
3. 카툰 랜드가 파괴되면, 먼저 자기 필드의 카툰 데몬즈 드래곤(`COC-05-001`)을 파괴한다.
4. 그 뒤 카툰 월드 가이드(`COC-05-008`)가 자기 덱에 남아 있다면 덱에서 묘지로 보내고, 묘지의 카툰 랜드를 빈 필드 칸에 **현재 체력 50**으로 부활시킨다.
5. 카툰 월드 가이드는 손패에서 일반 주문처럼 사용할 수 없고, 이 파괴 사건에 반응하여 덱에서 발동한다.

`src/cartoon-land.mjs`은 파괴 사건을 기록하고 드래곤 유지 조건을 먼저 처리한다. 가이드 주문은 공통 자동 유발 순서/대응으로 선언하고, 랜드 소환을 별도 대응으로 해결한다. 원래 랜드가 파괴되어 묘지로 이동한 사건은 유효하며, 이후 묘지 이탈/재진입은 해당 복구를 불발시킨다. 파괴 훅 안에서 부모 효과 스택을 즉시 실행하지 않는다.

## 테스트

- 카툰 랜드가 처음 0/1로 놓일 때 체력 지불
- 카툰 랜드 파괴 이후 드래곤이 먼저 묘지로 이동
- 월드 가이드가 덱에서 묘지로 이동한 다음 랜드가 체력 50으로 복구
- 월드 가이드가 덱에 없으면 부활 불가
- 카툰 랜드의 전투 파괴 방지와 효과 파괴 가능 여부
- 카툰 월드 가이드의 비정상 손패 발동 거부

## 남은 통합 검증

다른 카드를 통해 강제로 필드 밖으로 이동하는 경우는 **파괴와 다르며**, 이 연쇄를 발동시키지 않는다. 카드가 동시에 파괴되었을 때의 광역 트리거 정렬, 체력 0과 전투 파괴 방지의 상호작용, 타 플레이어의 카드 지배권 변경, 추가로 생성되는 카툰 랜드 등이 복잡하게 겹치는 사건은 이후 공통 반응 엔진 검증 대상이다.

## 개발자 해석과 밸런스 근거

전체 관련 덱 문구를 읽고 토우의 '병사 복제→소환 이력 성장→반환/부활', 언데드의 '사망·분열·회수', 용의 초반 일체화 확보, 버닝의 낮은 체력 구간 연계, 자연의 진화 회복을 보존하도록 정리했다. **실전 밸런스를 검증했다는 뜻은 아니다.**

8장(10-007,11-001,17-001,19-001/002/006/007,20-009)의 이전·이후 전체 런타임 레코드는 `card-patches.json`의 `TURN-CLAY-2026-10-16-DRAFT`에 기록했다. 원본은 f50f84c의 저장소 런타임 카탈로그이며, 부재한 v1.3 정본을 새로 만들지 않았다. 기본 ATK/HP 수치 변경 없음.

- 토우 재소환만으로 같은 실물을 반복 집계하는 성장을 막고 새 병사 복사·소환에는 성장 보상을 준다. 양쪽 병사를 집계하는 원문의 범위 유지. 형틀/노지귀는 기본값 복사로 강화의 지수 증폭과 다른 덱 혼합을 제한한다.
- 쌍둥이는 원본당 한 자식으로 해석했다. 자식을 반환·재소환해도 생성 계보 표시는 유지한다. 원본의 개별 턴 사용 제한은 다른 실물과 공유하지 않는다.
- 셔우롱 부활은 현재 턴 플레이어→상대, 각 필드 슬롯 순서의 직렬 소환이다. 파괴 사건 유발을 모아 대응한 뒤 대기열을 진행한다. 선행 부활이나 장착으로 묘지에서 이동한 실물은 재부활하지 않는다. 셔우롱이 이미 예약한 공격 금지는 다른 경로로 먼저 부활해도 그 턴 유지한다.
- 이무기는 기존 구현의 덱 출발점을 명시했다. 각 실물은 별도 선언하고 해결 때 용/드래곤 부재를 다시 검사한다. 반환 예외가 명시된 감독관만 일반 소스 생존 검사에서 제외한다.
- 와이번의 '자신'은 플레이어 피해 비용으로 정비해 체력 구간 연계를 살린다. `damage:true` 비용은 방패 피해 감소를 적용하고, 일반 HP 지불/리로드에는 적용하지 않는다. 이 구분은 같은 공통 비용 경로의 기존 갈퀴 피해 비용에도 반영한다.
- 파라오의 '필드에 존재하는 몬스터'는 양쪽 현재 몬스터에 일회 적용한다. 기존 아군만 강화하던 코드의 범위 오류를 수정했다. 호루스가 나중에 떠나도 무효가 되지 않는 확정 문구 유지.

기존 공식17재정, 마검의 자체 비용/다음 턴 배율, 임의 장착 해제 금지, 간드레이 자기 제외, 진화 기본값 교체/원형 복원, 윈드 걸 몬스터 한정, 원소4종의 플레이어별 공유1번, 무효 소환 원래 영역 유지 및 비용 미반환은 변경하지 않았다. 이번 새 해석을 사용자가 개별 확정한 공식 재정으로 표시하지 않는다.

## 공통 처리·복구

- `revivalQueue`를 빌헬름 전용에서 실물 원래 영역/소유자/체류 세대/조종자/종류를 보존하는 효과 소환으로 확장. 기존 빌헬름 once 상태 유지. 개별 소환은 기존 `pendingExtraSummon`/R22/UI/AI를 그대로 통과한다. 빈 칸·사용 금지·출발 영역 이탈/재진입은 재검사한다.
- 셔우롱/노지귀의 실제 묘지 부활 선택은 묘지 효과 사건으로 연결해 베리아/스트로베리아 유발을 모은다. 일반 생성·mill만으로 묘지 발동을 날조하지 않는다.
- 형틀은 기존 공개 필드 대상/옵션, 노지귀는 기존 선택권자 전용 선택 화면 사용. AI 세 난이도 모두 같은 합법성 API와 대응 큐 사용; 전술 품질 검증은 보류.
- DRAW와 END는 남은 부활/유발을 기다린다. 마지막 부활 후보가 무효가 되어 대기열이 비어도 같은 요청에서 보류된 턴 시작 후속을 재개한다.
- `draw`/리로드/덱 위 묘지 이동에도 영역 세대를 기록하여 덱·묘지 이탈 후 재진입을 이전 체류로 오인하지 않도록 보완했다.
- 시신 섭취 첫 파괴 회복은 별도 JSON 대기 그룹으로 모아 기존 자동 선언 순서를 사용한다. 파괴 중인 부모 스택을 덮어쓰거나 다른 실행기에 회복 항목이 섞이는 경우를 피한다. 회복 대기 중 조기 승패 결정을 보류한다. 전역 모든 동시 효과 순서를 완성했다는 뜻은 아니다.
- 새 이력·선택·대기열은 JSON 직렬화 가능한 데이터만 사용한다. 향후 D1 저장 어댑터에서 보존할 수 있는 형태이며, 실제 D1 연결/스키마 마이그레이션/운영 배포는 하지 않았다.

# 엑스트라 21종 소환 무효화 — 2026-10-14

관련 #22/#23/#25/#26/#27. P0 공통 체인의 기존 pass 전용 엑스트라 소환 창에 스톰블레이거의 실제 소환 무효화를 연결한다. 카탈로그 원문은 유지하며 없는 v1.3 정본을 만들지 않는다.

## 사용자 확정과 적용 범위

R22의 소환 선언 → 합법성·소재 검사 → 비용 지불 → 상대 대응 → 소환 해결, 무효화 시 비용 미반환은 기존 확정이다. 이번에 무효된 엑스트라 몬스터 자체의 이동 장소를 확인했고 사용자는 **“엑스트라 덱에 유지”**로 확정했다. 패 일반 소환의 무효 카드 이동까지 이번 답변으로 결정하지 않는다.

현재 `EXTRA_RECIPES`의 **21종**(영웅5, 블랙 메탈5, 지니어스2, 용4, 원소5)에 적용한다. 각 몬스터의 고유 효과 전체 자동화 완료가 아니다. 대응 창 밖의 일반 패 소환, 효과 소환/부활, 토큰 생성, 직접 수동 판정 소환은 아직 이 경로에 포함되지 않는다.

사용자는 이어서 스톰블레이거(COC-14-001) 원문의 “주문의 발동 또는 몬스터의 소환을 한 게임당 1회”가 **동일 카드의 주문/소환 무효화 합계 1회**라는 설명에도 “아 그럼 맞아. 계속해줘”로 동의했다. 주문 1회+소환 1회의 별도 횟수가 아니며 다른 카드까지 적용하는 전역 제한이 아니다.

## 선언·비용·선택·해결

1. 자기 MAIN에서 `extraSummon`을 선언한다. 기존 레시피/소재·주문·공간·선택 대상·턴당 사용 제한 검사를 통과한 뒤 비용을 지불한다.
2. `extra-summon-resolution`을 JSON LIFO 스택에 올린다. 상대는 `extraResponse`로 pass하거나 유효한 자기 일체화 스톰블레이거를 선택한다.
3. 무효화는 주문/소환 절 합계 **같은 물리 카드 게임당 1회**다. 기존 `spellCounterGameUsed`를 재사용하여 저장 상태와 호환한다. 선언 즉시 사용 횟수를 소비하고, 소스가 이동하거나 효과가 불발해도 돌려주지 않는다.
4. 카운터를 후발 선언한 뒤 소환 선언자가 pass하면 카운터 → 소환 순으로 해결한다. 카운터 소스 이탈/재진입·효과 무효·조종자 불일치는 불발한다. 유효한 카운터는 원 소환만 무효화한다.
5. 무효화된 몬스터는 엑스트라 덱에 남고, 소재와 사용 주문은 비용으로 지불된 상태를 유지한다. 소환 효과·얼라이즈 소재 부착·필드 파괴 유발을 새로 발생시키지 않는다. 비용으로 이미 발생한 사건은 취소하지 않는다.
6. pass 성공은 기존 소환과 후속 처리를 유지한다. 해결 전 소환 카드가 엑스트라를 떠났거나 필드 공간이 없으면 기존 실패 처리대로 종료한다. 타 영역의 카드를 강제로 끌어오지 않는다.

다른 행동과 임의 `negate` 요청은 거부한다. 현재 대응권자·등록 카드·소스 소유/영역·효과 무효·게임당 제한을 서버에서 검사한다. HTTP 실패는 방 버전·비용·사용 기록·스택·파일 저장을 함께 복구한다.

## 웨이크업 드래곤 — R23 보완

기존에는 소환 성공 뒤에만 END 패 복귀를 예약했다. 이제 주문 비용 지불 시 예약하므로 **소환 무효와 무관하게 END에 주문이 묘지에 남아 있으면 패로 복귀**한다. 중복 예약하지 않으며 주문이 이미 다른 영역에 있으면 복귀하지 않는다. 이전 pass 전용 저장도 대응 해결 시 누락된 예약을 보완한다.

## UI·AI·저장과 증거

- PvP 화면은 현재 대응자에게만 스톰블레이거 선택을 제공한다. 카운터 선언 후에는 원 소환자가 pass한다. 비용 미반환·주문/소환 합계 게임당 1회를 표시한다.
- 하/중/상 AI 모두 같은 합법 후보와 `extraResponse` API로 상대 소환에 대응하고 자기 소환에 대한 카운터를 확인한다. 상대 비공개 패/엑스트라·덱 순서를 입력으로 추가하지 않는다.
- 기존 pass 전용 저장에는 소환 스택 항목을 응답 시 보완한다. 새로운 소환/카운터 대기 상태는 JSON 저장·서버 재시작 후 동일하게 복원한다. 내부 엑스트라 UID와 스택은 상대 공개 상태에 노출하지 않는다.
- `tests/summon-counter.test.mjs`: 21종 성공/무효 경로, 비용 미반환·소환 효과 미실행, 소스 이탈/무효/재진입, 사용 제한 공유, 잘못된 선택·등록 실패, AI3난이도, 구 저장 호환, R23, 항복·대상 이동.
- `tests/summon-counter-api.test.mjs`: 실제 21개 방의 선언/카운터 재시작, 인증/버전/재전송 거부, 비용 후 내부 실패의 디스크/상태 롤백, 숨김 정보 검사.
- `tests/ability-ui.test.mjs`: 대응권자 선택과 원 소환자의 pass 제출, 버전 전달. DOM 계약 테스트이며 전체 브라우저 QA는 별도다.

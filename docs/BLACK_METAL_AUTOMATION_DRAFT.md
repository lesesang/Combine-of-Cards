## 규칙 해석과 실물 사용 기록

근거는 저장소의 `c285a9e` 런타임 카탈로그와 연결된 확정 규칙이다. 없는 v1.3 DOCX/원본 비교 JSON을 생성하지 않았다. 사용자 위임에 따른 **개발자 개정**이며 새 사용자 개별 확정이라고 표시하지 않는다. `card-patches.json`에10장 전체 전후/근거/이유를 보존했다.

- 1번 효과는 자신의 MAIN에 실제 카드별 턴1회. 이번 턴의 **기본** 공격력과 **기본 공격 기회 총량**을 바꾸며 기존 강화·약화·추가 공격·마검 배율을 별도로 유지한다. 영구적으로 약한 몸으로 바뀌거나 발동 때 사용한 공격권을 충전하는 것으로 해석하지 않았다. `blackMetalMode`를 별도 임시 층으로 두었다.
- 2번 비용 효과에는 문구에 없는 일괄 턴1회를 추가하지 않았다. 팔콘/램/샤크/드래곤/제네럴은 남은 공격 기회만큼 반복 가능하다. 솔저의 체류1회와 가드너의 게임1회는 각각 선언 비용 지불 때 소모한다. 무효화/대상 불발은 비용을 환불하지 않는다. 다른 실제 카드나 효과1과 제한을 공유하지 않는다.
- 솔저는 필드 이탈/재소환 때만 체류 사용을 초기화한다. 가드너 게임 사용 기록은 패·덱·묘지 왕복에도 유지한다. 필드 간 조종권 변경은 두 제한을 복구하지 않는다. 일반 물리 UID/효과 사용 장부에 효과 번호를 별도로 기록한다.
- **R29 유지:** 공격 금지·동결·ATK0과 남은 공격 기회는 별개다. 이 비용은 공격 선언이 아니며 오로치/키메라/나이트의 실제 공격 사건으로 세지 않는다. 효과 자체가 무효/봉쇄 상태인 소스는 발동할 수 없다.
- 이미 해결된 전환/강화/약화/가드너 보호는 부여 결과다. 이후 소스 무효나 소스 이탈이 대상에게 부여한 효과를 소급 취소하지 않는다. 키메라의 인쇄된 지속 보호·매지션 카운터 참조는 소스 무효 시 중단한다.
- 가드너 보호는 양쪽 필드의 블랙 메탈 몬스터 중 지정한다. 대상 필드 체류가 끝나면 종료한다. 키메라 보호는 현재 조종자의 일체화 존재에 따르며 일체화 카드 효과의 무효와는 별개다. 직접 파괴 보호는 전투 피해·비파괴 이동·상태 기반 사망을 막지 않는다.
- 드래곤 약화는 다음 발동자 턴 시작까지, 제네럴 강화는 이번 턴 동안이다. 임시 수정 배열에 적용량/기한을 저장하여 만료 때 다른 버프를 빼지 않는다. 제네럴은 받는 카드의 현재 강화 배율을 적용하고 약화100은 배율을 적용하지 않는다. 양수 실제ATK가 약화로0이 되면 기존 감소 상태 규칙의 파괴로 처리하며 처음부터 ATK0인 몬스터의 공격 가능은 바꾸지 않는다.

## 공격 사건·카운터

`defend`의 유효한 공격 실행 시점에서 실제 대상을 기록한다. 취소한 공격/재선택 대기/플레이어 공격/공격 기회 비용은 제외하고, 다이스0·피해 방지로 피해0인 실행 공격도 센다.

키메라는 같은 실제 대상이 그 턴에 여러 번 공격받거나 떠났다가 돌아와도1장이다. 자신의 현재 필드 체류 이력을 쓰며 이탈 시 비운다. 무효 중 실행 공격도 이력으로 남지만 END 선언 및 해결 때 유효한 같은 소스/조종권/체류가 필요하다. END 유발을 공통 대기열에 넣고 대응과 하위 사건이 끝난 뒤 다음 턴으로 진행한다.

나이트는 **실제 나이트 UID × 실제 대상 UID × 턴**마다1회 선언 예약한다. 복수 나이트의 횟수를 전역으로 합치지 않는다. 동일 실물이 이탈/재진입해도 그 턴의 이미 예약한 대상 기록을 지우지 않으며 무효 시 재충전하지 않는다. 성공한 카운터는 공격 당시 대상 조종자의 필드에 적립한다. 대상이 공격으로 파괴되어도 필드 카운터는 남지만 나이트 소스의 이탈/재진입·조종권/무효 상태 변경은 유발을 불발시킨다.

매지션은 양측에 현재 남아 있는 카운터 합계를 기본 공격 기회로 쓴다. 0을 `||1`로 바꾸던 서버/공격 UI 기본값 경로를 수정했다. 효과 무효 중에는 인쇄 효과가 없는 기본1회로 돌아가며 이미 소모한 횟수를 초기화하지 않는다. 카이저 등의 추가 공격은 별도로 더한다. 실제50/조건용250은 그대로 유지한다.

## 응답·선택·UI·AI·저장

필드 효과가 여러 개일 때 서버 명령 `effectNumber`와 UI 효과 선택을 추가했다. 소스/대상 UID·필드 체류·조종자·무효를 선언/해결 시 재확인한다. 윈드 걸은 이 몬스터 효과들을 대응 대상으로 보지만 기존 몬스터 전용 범위는 넓히지 않았다. 검색은 응답 후 선택하며 덱 후보는 선택권자만 본다. 솔저는 기존 묘지 효과 선언 사건으로 연결한다.

화면에 두 효과별 선택 가능 여부, 공격 기회 잔량, 솔저/가드너 소모, 필드 카운터를 표시한다. AI는 같은 합법성 함수를 쓰며 모드 선택과 검색/회복/보호/강약화, 중·상 난이도의 나이트/키메라 미공격 대상 우선 선택을 작성했다. 3난이도 전략 품질/완주를 검증했다는 뜻은 아니다.

추가 상태는 숫자·배열·객체의 JSON이다. 필드 이탈 정리와 조종권 유지, 턴 만료를 공통 경로에 연결했다. D1 연결/원자 요청·재접속 검증은 별도다. 옛 방에서 생성하지 않았던 과거 블랙 메탈 카운터/공격 이력은 소급 창작하지 않는다. 현재 저장에 이미 존재하는 필드는 읽지만 이력이 없으면0/새 기록으로 시작하며 구 방 버전 고정·이관은 남는다.

# 스톰블레이거 드래곤 — 주문 대응 부분 구현

현재 저장소의 플레이용 카탈로그 `COC-14-001` 효과 1은 “상대의 주문의 발동 또는 몬스터의 소환을 한 게임당 1회 무효화 합니다.”이다. 원본 v1.3 DOCX/JSON은 아직 없으며 이 구현은 해당 런타임 문구와 확정 엔진 정책을 기준으로 한다. 카드 문구·수치와 17개 공식 재정은 변경하지 않는다.

- 발동: 상대가 `src/spell-response-registry.mjs`의 16종 중 하나를 선언한 대응 창. 자신의 유효한 스톰블레이거 일체화 카드만 선택 가능하며, 손패/상대 조종/무효 상태/이미 사용한 소스는 거절한다.
- 비용과 제한: 추가 HP/버리기 비용 없음. 같은 물리 카드 UID에 게임당 1회 사용 기록을 선언 시 소비한다. 영역 이동·재일체화·JSON 저장/재시작으로 초기화하지 않는다. 후속 소환 무효 구현도 같은 기록을 사용해야 한다.
- 순서: 주문 선언과 비용 지불 → 상대 카운터 선언 → 원래 주문 발동자의 pass → 카운터부터 LIFO 해결 → 무효화된 주문 핸들러를 실행하지 않음. 비용과 사용 횟수는 반환하지 않는다. 이 카운터는 주문 카드가 아니므로 스톰블레이거로 다시 카운터할 수 없다.
- 소스: 해결 시 소스 이탈/조종권 변경 또는 효과 무효이면 카운터가 불발하고 원래 주문을 해결한다. 카운터 사용 기록은 유지한다. 필드 발동의 소스 이탈 무효 정책을 적용하며 독립 지속 효과 예외로 취급하지 않는다.
- 서버/UI/AI: 동일한 `spellResponse` 행동을 사용한다. 공개 응답에는 현재 대응권자·카드명·본인에게 합법인 소스 선택만 담고 비공개 패/덱 순서와 내부 스택은 노출하지 않는다. 세 AI 난이도 모두 합법 카운터가 있으면 사용하며, 추가 전략 차이는 미구현이다.
- 원자성: 불법 선언은 사용 기록·버전·비용 불변. API 처리 실패는 방 스냅샷을 복구한다. 중복/오래된 `expectedVersion` 요청을 거절하며 카운터 대기 중 재접속과 서버 재시작을 지원한다.

**남은 범위:** 이 카드의 몬스터 소환 무효화, 나머지 주문의 대응 창, 다른 무효화 카드, 일반 필드/묘지/복사/파괴 체인, 모든 소스 이동·복사 조합. 따라서 스톰블레이거는 **partial**이며 전체 인증은 0이다. R22 비용 미반환은 이미 확정된 규칙이다. 소환 실패 카드의 후속 영역 처리 등 연결 작업에서 근거가 부족하면 확정 규칙과 별개로 출처를 먼저 대조한다.

검증: `tests/storm-spell-counter.test.mjs`(16종 해결 차단·비용 유지·소스·제한·AI), `tests/storm-counter-api.test.mjs`(인증·버전·재시작), `tests/ability-ui.test.mjs`(선택 및 제출). DOM 계약 테스트는 실제 브라우저 렌더링 검증을 대체하지 않는다. #22/#23/#25/#27의 일부 구현이며 이슈 완료 조건 전체는 충족하지 않는다.

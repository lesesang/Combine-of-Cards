## 뜨임질: 선택 가능한 유한 연속 공격

`src/attack-sequences.mjs`와 `pendingAttackSequence`는 소스 UID·일체화 체류 세대·턴·남은 적 UID/필드 세대·선택 단계를 JSON으로 저장한다. 주문 해결 시점의 상대 필드 몬스터와 플레이어가 목록이며, 일체화와 플레이어를 두 명으로 중복 세지 않는다. 공격할 대상을 고를 때와 실제 공격을 해결할 때 모두 합법성을 검사한다. 소스가 이탈하거나 현재 합법 대상이 없으면 종료한다.

강제 대상이 여러 개면 발동자가 그중 선택한다. 한번 공격한 강제 대상이 생존하여 다른 대상을 막으면 남은 공격은 종료한다. 소멸한 대상에 대한 공격을 다른 적에게 돌려 같은 적을 두 번 때리지 않는다. 새로 소환되거나 떠났다 돌아온 적을 목록에 추가하지 않는다. 이는 확정된 어그로 재정을 보존하는 해석이다.

효과가 직접 지시하는 공격은 MAIN의 주문 해결 후 실행하고 일반 공격 기회는 소모하지 않는 개발자 해석을 기록했다. 일반 ATTACK 진입을 대신 만들지 않으므로 마검30HP 비용이나 황금 ATTACK 유발을 임의로 발동하지 않는다. 공격은 기존 `defend`/공격 다이스/전투 피해/파괴/마검 처치/추가 유발 경로를 사용한다. 각 타격은 별개 다이스이며 공격력0은 다이스를 굴리지 않는다. 생성된 유발·부활·선택이 끝나야 다음 공격을 선택한다.

+100은 기본 공격력과 다른 독립 임시 층이다. 기존 무기·누적 강화·마검 배율과 합성하고 진화 시 기본값 교체에 섞지 않는다. 효과가 해결된 후 소스 효과 무효로 부여가 소급 취소되지 않으며 END/비필드 이동에서 제거한다. 공격 불가여도 이미 해결된 +100은 남을 수 있다. 다른 실물의 뜨임질은 별개로 발동할 수 있다.

PvP에 다음 대상 선택 화면을 추가하고 일반 행동 버튼을 잠근다. AI 하·중·상은 동일 합법 후보를 사용하며, 하 난이도는 무작위, 중/상은 현재 HP가 낮은 후보 우선이다. 이는 전술 품질 인증이 아니다. 종료·항복 시 공격 목록도 제거한다.

## 언데드·진화·횟수

- 등불은 검색 선택으로 바꾸지 않고 덱에서 먼저 만나는 몬스터를 공개 드로우한다. 첫 몬스터를 뽑고 다음 몬스터가 없으면 리로드하는 기존 확정은 유지한다. 비몬스터가 남아도 그 카드를 보존한 채 묘지와 합쳐 섞는 카드별 예외, 리로드 후 남은 드로우 시도, 다시 실패하면 종료하는 부분은 개발자 해석이다. 일반 드로우는 여전히 덱이 비었을 때만 리로드한다. 단지 덱을0장으로 만들었다고 일반 리로드를 추가하지 않는다.
- 공통 `reloadDeck`/`drawFailure`로 피드백100/150/200…·영역 세대·패배를 공유한다. 라팍스의 드로우 실패 패배는 효과 무효 중에는 적용하지 않는다. 등불의 +100/+100은 가져온 패 몬스터에 남아 이후 소환에서도 유지하고 다른 비필드 이동에서 일반 초기화한다.
- 강령의 조건은 프람덴베르카 UID/조종자/현재 일체화 세대별 파괴 이력이다. 비용으로 실제 파괴된 자기 몬스터도 세지만 단순 묘지 이동은 세지 않는다. 효과 무효는 조건의 역사 자체를 지우지 않는다. 이전 저장의 빠진 이력을 추정하지 않는다. UI에 현재 파괴 수를 표시한다.
- 강령의 빌헬름은 이미 카탈로그에 있는 생성 카드10-011만 사용한다. 새 원본 카드 자료를 창작하지 않는다. 새 실물은 기존 빌헬름 사망1회 부활 경로를 사용한다. 주문 무효 시 생성하지 않고, 소환이 무효화될 때만 출발한 패에 남긴다. 파괴3회는 조건이지 소모 비용이 아니다.
- 이번5종은 `TIMED_SPELL_IDS`에서 실물 UID/효과1/현재 턴 사용을 선검사하고 비용을 낸 뒤 기록한다. 선언/효과가 무효여도 횟수는 반환하지 않는다. 서로 다른 실물이나 효과 번호를 공유 제한하지 않는다. 기존 모든 주문의 횟수 기록을 전수 완료했다는 뜻은 아니다. 복잡한 원본 이동이 포함된 이5종은 재사용53종에 임의로 추가하지 않았다.

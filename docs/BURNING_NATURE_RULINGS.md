# 버닝 소울·자연속성 연속 턴 판정 (v1.3)

## 투지를 불태우는 버닝 소울 (COC-20-004)

- 자신의 필드에서 이름에 '버닝 데몬즈'가 포함된 몬스터 1장을 선택한다.
- 서버가 `1d5`를 한 번 굴린 뒤 `결과 × 100`만큼 자신 플레이어의 체력을 감소시키고, **정확히 같은 수치**만큼 선택 몬스터의 현재 공격력을 올린다.
- 플레이어 체력이 0 이하가 되면 기본 패배 규칙을 적용한다.
- 공격력 증가는 다른 별도 기간이 없으므로 몬스터가 파괴되거나 패·덱으로 이동할 때 초기화되는 일반 능력치 규칙을 사용한다.
- 자기 필드 밖의 카드를 대상으로 발동할 수 없다.

**R10 공식 확정(2026-10-13):** 자신의 몬스터 **1장만** 선택한다. 전체 강화는 허용하지 않는다.

## 물어뜯기 (COC-30-011)

- 플레이어마다 자연 속성 주문을 사용한 자기 턴의 전역 턴 번호를 `natureSpellTurns`에 저장한다.
- 현재 자기 턴이 전역 5턴이라면, 자기 직전 두 턴인 전역 3턴 및 1턴 **각각**에서 자연 속성 주문을 사용했어야 한다.
- 이번에 발동하려는 물어뜯기 자체는 직전 두 턴 조건에 포함되지 않는다.
- 조건이 성립하면 상대 플레이어 본체에게만 200 피해를 준다. 몬스터를 대상으로 변경할 수 없다.

**R09 공식 확정(2026-10-13):** 자신의 직전 두 번의 자기 턴 각각 자연 주문을 사용해야 한다. 상대 턴이나 이번 턴은 계산에 넣지 않는다.

## 테스트

`tests/burning-nature-history.test.mjs`는 자연 주문 사용 이력의 긍정·부정 조건, 피해 대상 검사, 버닝 소울의 단일 다이스와 피해/강화량 일치, 잘못된 강화 대상 거부, 필드를 떠난 뒤 공격력 초기화를 검증한다.

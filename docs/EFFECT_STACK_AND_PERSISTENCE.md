# 효과 스택 및 독립 지속 효과 (v1.3 / 개발 중)

## 적용한 공통 엔진

`src/effect-runtime.mjs`은 게임방 JSON에 저장 가능한 데이터만을 사용한다. 발동을 선언하면 `effectStack`에 추가되고, **나중에 발동한 효과부터 해결**한다.

- 일반 필드 발동: 해결 시 해당 카드가 필드나 일체화 영역을 떠났다면 무효화
- 예외: 파괴 시 발동, 묘지 발동, 발동자가 자신을 비용으로 보낸 경우, 독립적으로 등록된 지속 효과
- 동일 사건에서 자동 발동이 여럿이면 확정된 명시적 우선순위를 먼저 적용하고, 같은 우선도에서는 현재 턴 플레이어 효과를 먼저 선언한 다음 상대 효과를 선언
- `registerPersistent`는 발동한 카드가 묘지로 이동해도 별도 레코드로 카운터·앵커·종료 조건을 유지
- 해결 256단계 및 동시에 열린 효과 256개 상한은 **서버 보호용** 제한이며 새로운 카드 사용 횟수 규칙이 아님. 무한 루프 경고/진단과 합법적 반복을 구별하는 추가 작업이 필요

**주의:** 현재 일반 주문의 발동·대응을 모두 해당 스택으로 대체하지는 않았다. 아직 모든 카드에 대한 연쇄 선택권, 선언 시점, 대응 창, 원인별 무효화 검증은 남아 있다. 이 코드는 완전 자동 체인의 전단계다.

## 용·드래곤 덱의 실제 연동

- `COC-11-007` 탐욕의 악룡 파프니르: 덱 또는 패에 존재할 때 토큰이 생성되면 소환 가능한 빈 칸에 자동으로 소환
- `COC-11-008` 라인의 황금: 파프니르 소환 후 패에 생성되며 즉시 자동 발동. 카드 자체는 묘지로 가지만, 보물 수는 서버 `persistentEffects`에 보존. 새 토큰을 보물로 전환하면 카운터 +1 및 파프니르 공격력·체력 +10. 자신의 공격 페이즈 시작 시 카운터 +5 및 공격력·체력 +50
- `COC-11-009` 니벨룽겐의 반지: 파프니르 파괴 시, 황금 종료 전에 기록된 보물 수를 가져와 수 × 10만큼 플레이어 체력과 공격력 상승. 반지는 게임에서 제외되고 황금도 삭제. 플레이어 공격력 보너스는 이후 일체화에 적용
- 파프니르는 이 시스템에서 토큰 사용/생성에 의한 자동 소환만 가능하며 손패 일반 소환은 거부

## 여전히 확인할 충돌 및 애매함

1. '토큰 사용'이 생성 외의 모든 효과/비용/릴리스를 포함하는지, 이벤트 구분 필요. 현재 구현은 **생성 사건만** 자동으로 수신한다.
2. 양쪽 플레이어 모두 라인의 황금을 보유한 경우 한 개의 토큰을 각 황금에서 보물로 계산하는지. 현재는 전역 토큰 1회 생성에 각 활성 황금이 카운터 1개를 얻는 구현이며, 별도 확정 재정이 없다.
3. 생성된 토큰이 황금으로 전환될 때 필드에서 사라지는 방식. 현재는 생성 후 파괴를 거치지 않고 게임에서 사라지며, 파괴 시 발동 효과는 발생하지 않는다.
4. 파프니르가 소환될 필드 공간이 토큰 생성 때문에 부족한 경우: 현재 성공적으로 필드에 생성된 토큰 사건을 기준으로 파프니르 소환을 검사한다. 생성 전·후 슬롯 처리의 추가 재정이 필요하다.
5. 플레이어 공격력과 일체화 공격력의 관계: 현재 링 보너스를 게임 내 플레이어에 저장하고 일체화 중/이후에 공격력으로 추가한다. 플레이어 자체 공격 시스템의 완전한 독립 모델은 추가 구현이 필요하다.

확정되지 않은 분기까지 임의로 '완전 자동화'로 선언하지 않는다.

# 블랙 메탈 퓨전 업·크래쉬볼티지 자동화 범위

기준: 카드 v1.3 / 엔진 beta.10 / 이슈 #25·#23·#26·#27. 원문은 이전 `03_카드_데이터_v1.3.json`의 두 카드와 현재 카탈로그를 대조했다. 카드 수치/문구는 변경하지 않았다.

## 실제 지원

| 카드·효과 | 발동·조건 | 비용·선택 | 해결·횟수 |
|---|---|---|---|
| COC-22-008 효과 1 | 자신의 메인, 패의 지정 주문, 레시피/공간·사용 금지 검사 | 패·필드의 지정 소재를 선택 | 기존 퓨전 소환, 효과 1 턴당 1회 기록 추가 |
| COC-22-008 효과 2 | 자신의 메인, 자신의 묘지의 카드, 이번 턴 미사용 | 자신의 블랙 메탈 필드 몬스터가 가진 공격 기회 1회 | 같은 UID를 자신의 패로 회수. 효과 1과 별도 제한 |
| COC-12-013 효과 1 | 자신의 메인, 자신 조종 필드의 유효한 크래쉬볼티지 | 손패 1장 버리기, 상대 필드 몬스터 1장 선택 | 직접 효과 파괴. 면역이면 파괴하지 않지만 비용/횟수 소모. 기본 턴당 1회 |
| COC-12-013 효과 2 | 전투 파괴 후 | 추가 비용 없음 | 기존 피어스 보이 방식의 임시 관통: 실제 피해 - 피해 직전 HP, 하한 0 |

사용하기 전 모든 필수 비용·대상·위치·횟수를 검사한다. 불법 행동은 비용/카드/사용 기록을 남기지 않는다. 회수 때문에 공격 선언·전투 피해·전투 파괴 사건을 만들지는 않는다. 추가 공격 기회는 기존 공격 엔진과 동일하게 소비하고 다음 턴에는 새 턴의 한도를 사용한다.

회수와 소환 순서는 어느 쪽이 먼저여도 각각 한 번씩 가능하다. 회수→소환→회수 또는 소환→회수→소환으로 같은 효과를 반복하는 것은 거부한다. 카드 위치 이동이나 JSON 저장/복원으로 이 기록이 지워지지 않는다. 일반 손패 사용 버튼으로 퓨전 업만 소모하려는 경우 엑스트라 소환 메뉴를 안내한다.

## 화면과 AI

- **묘지 카드 효과**에서 공격 기회 비용으로 쓸 몬스터를 선택하고 회수한다. 서버가 제공하는 현재 합법적인 본인 선택지만 사용하며, 실행 시 다시 검사한다.
- **필드 카드 효과**에서 크래쉬볼티지를 고르면 비용 필드가 “묘지에 버릴 손패 1장”으로 표시된다. 상대 필드 몬스터를 지정한다.
- AI는 같은 묘지 비용 검사와 실제 행동 API를 사용한다. 크래쉬볼티지는 파괴 면역인 상대를 피하고 자신의 손패에서 비용을 고른다. 이 작업은 상·중·하 전략 전체를 완성하지 않는다.
- 비공개 손패/덱과 효과 사용 내부 기록은 상대에게 전달하지 않는다. 공개 로그에는 버린 카드명과 공개된 공격 비용만 기록한다.

# 전투 판정 자동화 확장 — v1.3

실제 코드에서 지원한 개별 전투 특례:

- `COC-26-011`: 하이퍼 무쌍 매치는 전투 피해로 체력이 0 이하가 되어도 체력 1로 살아남음. 효과/비전투 피해에는 이 보호를 적용하지 않음.
- `COC-12-011`: F=HERO 버디 히트토네이도가 전투로 상대 몬스터를 파괴하면 파괴 직전 공격력을 참조하여 상대 플레이어에게 추가 피해.
- `COC-12-008`: F=HERO 피어스 보이의 관통 피해는 실제 전투 파괴를 기준으로 계산.
- `COC-32-003`: 원소의 마법사 윈드의 직접 공격에 1d6×50 추가 피해.
- `COC-32-013`: 드래곤 위저드 허리케인의 직접 공격에 1d6×100 추가 피해.
- `COC-32-001`: 원소의 마법사 플레임은 몬스터 공격에서 자신의 공격력이 대상보다 높으면 그 턴 추가 공격권 획득.
- `COC-32-011`: 드래곤 위저드 볼케이노는 공격으로 몬스터를 파괴하면 그 턴 추가 공격권 획득.

기존 2회 공격 카드 규칙은 유지하며, 추가 공격 횟수는 해당 턴으로 한정한다. AI는 서버의 공격 가능 횟수 판정을 사용한다.

## 아직 정식 완료 판정할 수 없는 부분

이 확장은 대응 효과 체인, 사용 횟수·효과 복사, 동시 파괴 및 공격력 변경시 재계산의 모든 경우를 검증하지 않는다. 파괴의 순간과 전투 피해의 세부 순서, 공격자가 파괴/소멸했을 때 후속 효과 등은 공통 이벤트 시스템에서 통합 구현할 필요가 있다. 테스트가 통과하더라도 모든 254개 카드 효과가 자동화된 것은 아니다.


`COC-12-013` 크래쉬볼티지에도 기존 피어스 보이의 관통 훅을 연결했다. **실제 피해 - 피해 직전 HP** 및 **전투 파괴만 적용**은 현재 코드의 임시 기준이며, 원문의 공격력/효과 파괴 해석은 OPEN_RULINGS_REGISTER의 R28에서 추적한다.

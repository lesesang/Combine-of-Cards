## 이번 수정

기존 황금은 보물이 늘 때 `unit.atk/hp`에 증가량을 바로 더했다. 파프니르가 무효화된 동안 보물이 생기면 성장 이력을 잃고, 이미 더한 수치는 무효화로 구분할 수 없었다. 황금 소유자의 필드에서만 파프니르를 찾았으므로 조종권을 빼앗긴 실제 파프니르는 이후 성장이 끊겼다. 새 `dragon-growth.mjs`는 다음을 구분한다.

- `fafnirResidence`: 실제 필드 진입 때 증가하는 체류 번호. 조종권 변경/트레이드의 필드 간 이동은 새 진입이 아니다. 일반 `fieldRevision`의 대상 유효성/조종권 변경 검사는 그대로 유지한다.
- `fafnirGrowth.treasures`: 이번 연속 필드 체류 중 연결된 활성 황금에 실제 추가된 보물 수. 하나의 황금 사건을 중복 기록하지 않고, 같은 실물에 연결된 여러 황금의 서로 다른 추가 사건은 합산한다.
- 성장 ATK: 보물 수×10을 받는 파프니르 기준 공통 강화 배율로 계산한 지속 보너스. 기본/일회성 강화와 분리하여 실제ATK·마검 배율에 반영한다.
- 성장 HP: 이전에 적용한 지속 HP 증가량과 새 증가량의 차이만 반영한다. 기존 피해를 지우거나 매번 전체 보물만큼 다시 회복하지 않는다.

무효화 중에도 보물 사건은 기록하되 성장 보너스는0이다. 무효가 풀리면 기록한 보물에 대한 보너스를 되살린다. 조종권 변경은 기록을 유지하고 받는 쪽의 현재 용왕/꽝철이 배율로 다시 계산한다. HP 증가분이 제거되어0 이하가 되면 일반 체력0 파괴 경로를 따른다. 기록된 보물×10 전체에 공통 배율을 결합하여 한 번 버림한다.

필드를 떠나면 성장 층과 그 체류의 기록을 제거한다. 재소환은0에서 새로 센다. 필드 밖에 있을 때 황금이 모은 보물을 다시 들어온 파프니르의 과거 성장으로 더하지 않는다. 이미 적용된 독립 황금은 비파괴 이탈만으로 종료하지 않고 보물/어택 시작 경로를 유지한다. 황금의 소유자와 보물은 그대로이며, 다시 필드에 있는 동일 실물의 이후 보물만 새 성장에 더한다.

## 황금·반지의 연결 생애

황금/반지를 생성할 때 실제 파프니르UID와 체류 번호, 서로의 연결을 저장한다. 최초 황금 해결은 같은 연속 필드 체류를 요구한다. 생성 후 조종권만 변경된 경우는 허용하지만 이탈 후 재진입한 파프니르에 옛 미적용 황금을 붙이지 않는다. 미적용 황금은 원래 파프니르가 필드를 떠나면 `lapsed`로 표시하여 재진입 후 패 재활용으로 되살리는 경로를 막는다. 이미 적용된 황금은 이 제한으로 끊지 않는다.

실제 파프니르 파괴 시 모든 연결된 활성 황금을 `closing`으로 만들고, 각 황금에 연결된 반지와 그 황금의 보물 스냅샷을 사용한다. 이때부터 동일 황금의 재사용을 막는다. 반지는 황금 소유자의 패에 있고 주문 사용이 가능하며 그 실제 카드의 이번 턴 사용 횟수가 남아야 한다. 자동 사용 시 실물 횟수와 사용 카드/주문 수를 기록하고 묘지로 보낸 뒤 기존 공통 주문 대응을 받는다. 무효 시 강화 없음/반지 묘지 유지, 원본 묘지 이탈·재진입도 불발이다. 반지 해결/무효 후 황금을 제외하고 지속 효과를 종료한다.

황금 첫 사용이 무효화되었거나 아직 해결되지 않아 활성 지속 효과가 없는 연결도 실제 파프니르 파괴 시 종료하고 황금을 제외한다. 이 경우 적립된 보물이 없으므로 반지 보상을 새로 만들지 않는다. 이미 `closing`인 활성 황금은 미적용 황금 정리에서 제외하여 반지보다 먼저 지우지 않는다. 독립 황금 원본 카드의 패/덱/묘지 이동만으로 이미 쌓인 보물을 초기화하거나 같은 실물 지속 효과를 중복 등록하지 않는다.

공식R05 네 토큰 사건/R06 한 사건 한 황금·조종자 측 우선/R07 파프니르 선행 및 비파괴 전환/R08 플레이어 ATK·HP 영구 보상은 유지한다. 같은 쪽 여러 황금의 기존 선등록 우선도 그대로다. 파프니르 생성 유발1번의 실물별 턴 사용 제한과 상대 몬스터 효과 대응은 바꾸지 않는다. 재소환해도 같은 턴의 생성 사용 횟수를 환급하지 않는다.

## 화면·AI·이전 저장

필드 파프니르에는 이번 체류 보물 수·현재 적용 성장 보너스를 표시한다. 실제ATK는 공통 계산을 사용하며 AI의 필드 대상/제물·처치 우선순위 비교도 실제ATK를 참조하도록 수정했다. 피격 몬스터 처치의 공격력 기반 보상도 분리된 성장 층을 누락하지 않도록 실제ATK 스냅샷을 사용한다. 이것은 AI 전술 품질/완주 검증 결과가 아니다.

**구 저장을 추측해서 이관하지 않는다.** 이전 방은 황금 총 보물 수만 남고 실제로 더했던 성장량/무효 중 누락/당시 배율을 알 수 없다. 필드의 파프니르에 새 기록이 없으면 기존 수치를 그대로 두고 앞으로 관측한 보물만 새 기록으로 관리하며 `legacyUntracked` 표시를 남긴다. 화면에도 이전 성장 이력이 미분리라고 표시한다. 필드 이탈 후 정상 신규 체류부터 정확한 새 기록으로 시작한다. 옛 황금 최초 사용의 체류 정보가 없으면 기존 엄격한 `anchorRevision` 검사를 보존한다. 진행 중 방의 버전 고정/명시적 이관은 별도 잔여다.

새 기록은 JSON 객체와 숫자/불리언이다. 함수·타이머·Map을 방에 저장하지 않으며 기존 요청 롤백/저장 경로를 따른다. 개인 D1의 실제 저장·CAS·재접속·동시 요청 검증은 아직 하지 않았다.
